# 共享目录与跨模式删除第二阶段验证

建立时间：2026-10-17 06:39:25（Asia/Shanghai）。实现说明见[共享课程目录与跨模式数据协调](../docs/00021_20261017063925_共享课程目录与跨模式数据协调.md)，承接[独立核心首阶段验证](00034_20261017002113_课文闯关独立核心首阶段实现与验证.md)。

## 1. 本次变更

实现共同的 `CatalogPort`、应用级依赖注入、共享快照与应用写入队列。七步页面使用同一共享状态，在最新 revision 上执行变更；闯关服务使用相同身份与材料，并在写入前核对真实共享选择和删除状态。

新增独立删除计划，收集两种模式资源后先落盘，再依次执行数据清理与引用检查。支持中断续作、重复清理、文件重试和永久身份标记；旧版资源清理队列可以接续。删除另一来源的混练题时保留当前课程的独立作答与已完成关卡。

七步快照仍使用原 key、原生历史槽和格式版本二；新增的变化是课程指定可引用尚无七步包的材料。七步页面对此显示待准备，空练习、空阶段和空音频不会冒充另一课程的已发布内容。原有题目、评分、七步教学与原资源标识未重新生成。

修正闯关核心只接受字母开头孩子 ID 的限制，兼容旧应用实际生成的数字开头十六进制 ID。材料快照可携带图片引用，以便跨模式核对资源存活情况；旧闯关快照没有这些可选字段时仍可读取。

## 3. 数据兼容核对

- 只读目录前后直接比较原 `lingonest.local.v1` 包装字符串，v1 与 v2 均不因读取或增加服务组合而主动写入。
- 共享目录同时保留内置课与原自建课程，课程 ID、孩子 ID 不重新分配。新材料保存为原格式内的独立课程记录，不产生七步任务。
- 七步页面与目录入口并发改名后，两处修改均保留；原 `courses / events / runs` 内容不变。
- 保存失败、过期材料和过期选择被拒绝时，不推进闯关作答、队列或发布指针。
- 普通归档不写闯关快照，恢复后原会话及输入可继续；课程指定按旧行为清除，不自动恢复。
- 彻底删除只移除目标内容；另一课程、另一孩子的事实保留，共享图片不误清理。混练完成记录与保留作答能继续通过新旧可选字段校验。
- 既有七步课程包、音频清单和评分投影摘要测试继续通过，不把闯关作答换算为七步学习事件。
