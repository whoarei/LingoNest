## 本轮结果

| 问题 | 处理后的体验 |
|---|---|
| 闯关轮次偏长、同表达反复选择 | 新准备内容使用 v2 预算：基础题 4～6 道、最多 2 道补练；根据新目标和必要复习覆盖决定题量。保留理解与独立回想，优先加入组句和不同任务。生成提示明确交流用途、角色回应与事实边界，避免仅换措辞凑题量。 |
| 示范后不知道怎样进入独立口语 | 提示练习完成后，以“独立再试一次”为主行动，创建独立尝试；原练习与录音继续保留。退出、冷启动及覆盖安装仍能恢复该独立尝试。S4 独立尝试隐藏突出的示范按钮，保留需要帮助的入口。 |
| 家长录音队列处理顺序不清楚 | 卡片标明独立尝试或提示练习，独立尝试优先排列，同类保持原先的时间顺序。仍须真实回听结束才能确认，提示练习不会变成独立测评证据。 |
| 审核题库难定位、无法体验题目 | 可按关卡、目标、审核状态筛选，显示分组进度。孩子视角预览复用实际选择、填空、排序与判分，允许撤回词块、重新试答和试听，不新增学习记录或审核决定。预览支持 Escape、Android 返回及焦点返回。 |
| 分组审核下一题跳出目标 | 实际体验发现“审核通过，下一题”仍从全局找题，现改为在当前组内向后找、再回到组内首题；组内完成时提示其他组剩余数。勾选后仍保留当前题，避免控件立即消失。 |
| 发布影响提示遗漏删除题目 | 分别显示新增、修改、移除题数，说明已有学习记录保留；教材或关卡变化仍单独提示，完整审核与音频条件继续生效。 |
| 首页、完成页信息太多 | 框架显示课程身份，插件显示今天的目标；七步压缩介绍、突出下一阶段，家长录音待办移到陪伴者卡片。完成页先显示练过什么及下一步，统计折叠；七步主要按钮保留继续行动与回到路线。 |
| Android 回车出现多余错误 | 实际系统回车触发时，自动保存可能排到提交之后，产生“当前题目已提交”提示。合并进行中的输入保存，提交前等待其完成，并防止已提交题目重复提交。最终 APK 中重做快速改答案与系统回车，只有一条作答，无错误提示。 |

框架继续负责导航、设置、家长入口、公共记录和退出；题目编排、答题、口语确认与模式报告由各学习模式插件负责。

## 兼容与数据保留

- 接受规则 v1/v2、调度标记 v1/v2；已有冻结题序不重排。旧发布包保留原审核题量上下限，新开始的旧包轮次遵守其原下限（通常为 6 道），只有新准备的 v2 内容使用 4～6 道预算。
- 七步独立尝试使用可选的 `purpose` 字段，不要求重建旧档案。恢复同阶段的最近一轮，避免重新进入早已被较新轮次替代的旧草稿。
- 沿用上一轮实际体验数据：七步 38 条事件、13 次作答；闯关 35 次作答。逐项核对旧课程、原七步事件、原闯关作答与发布包保持一致。
- 最终七步 53 条事件、18 次作答，闯关 48 次作答。新增事实均来自本轮练习与确认，原始事实逐项保留。最终覆盖安装前后两个模式与全局设置 payload 完全一致。
- 发布新候选内容仍按已有规则终止旧版本进行中的会话，保留原题序、输入和作答。审核草稿与当前可学版本独立。

## 实际体验过程

环境：Android 10 / API 29 / WebView 74，独立只读模拟器会话，手机 CSS 412×751、平板 CSS 1171×806。使用“My Family · 体验课”和“体验小树”，实际数据保存经过原生 SQLite，覆盖安装未清空应用。

1. 第一轮先压缩首页，走完提示练习，直接新建独立口语。退出、冷启动和第二轮覆盖安装后，独立标记、提示状态、输入和录音状态准确恢复，旧练习事实不变。
2. 独立录音完成后，主入口为请家长确认。真实播放本地录音结束才允许确认，确认后学习状态更新。提示练习保留，仍显示其作答条件。
3. 将原 24 道候选题整理为 12 道有不同任务的手工审核测试题，按目标查看每组 6 道；实际修改一题说明，在预览中看到最新内容、正确试答并用 Android 返回关闭，学习作答仍为 35 条。
4. 完成 12/12 审核、2/2 原生音频整理后发布；当前全局仍为七步，经统一设置切到闯关才开放给孩子。
5. 新第一关基础 4 题，主动查原文后故意答错，增加 1 道补练。保存未提交的 `family`，冷启动后同一会话及输入完全一致。实际完成对话选择、填空、理解、排序、听音补练；完成页直接指向下一关。
6. 第二关基础 4 题，覆盖旧目标复习与新目标的理解、回想、组句。两关总计 9 次作答，对比上一轮相同两目标样例的 17 次更短；这只是该测试样例，不能当作所有课程统一减半的保证。
7. 第三轮实际发现并修复回车与自动保存时序问题。再次覆盖安装，七步、闯关及模式设置 payload 逐字一致。进入本课复习，用 Android `input keyevent 66` 提交完整句子，新增一次作答且不出现错误提示；继续完成 4 题复习。
8. 最终七步完成页主按钮底部约 CSS y=538，小于手机视口高 751；仅有“独立再试一次”和“回到学习路线”，统计默认折叠。示范后原文只显示一次。
9. 实际修改两个目标下的题目，筛选“介绍妈妈的职业”，通过后仍到该目标下一题；该组完成时停留组内，并提示另一组还有 1 道待审核。新候选未发布，孩子当前版本仍可用。
10. 手机与平板均检查无横向溢出。平板保留路线与陪伴卡片的两栏布局。最后补齐独立录音优先排列，重新安装复查。
11. 最终版本面对 4 条待确认录音，将较早提交的独立尝试排在更新的提示练习之前，第一张卡片 ID 与原生保存的独立作答 ID 一致。
