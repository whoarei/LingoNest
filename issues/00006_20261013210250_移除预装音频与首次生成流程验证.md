设计：[用户配置生成课程音频与无音频安装包](../docs/00006_20261013210250_用户配置生成课程音频与无音频安装包.md)。

## 1. 修复范围

用户希望自己配置 API 并测试从零生成。已移除 APK 预制 WAV/清单和原生自动导入，首次显示 0 / 44；保留用户生成后的课程长期资源、暂停续作和离线播放。“恢复内置课程音频”改为明确删除本课音频，删除后不会补回默认声音，API 和学习记录保留。

未自动清除升级用户已有资源，以免误删自行生成的数据；安装过 0.1.3 的用户可在家长空间确认删除本课音频进行空状态测试。
