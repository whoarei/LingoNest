- 使用只读临时会话启动，不加载和保存快照；测试完成后退出该会话。安装、应用数据和显示尺寸调整均限定在本次模拟器，未向 `192.168.50.192:5555` 真机安装或写入数据。

## 自测发现与修复

| 问题 | 实际复现 | 修复与正式回归 |
|---|---|---|
| `Promise.allSettled` 不受支持 | 闯关体验加载时，来源图片组件抛异常，宿主显示加载失败 | [SourceImages.vue](../src/components/SourceImages.vue) 改用 `Promise.all` 加逐项捕获，保留部分成功结果与过期请求保护。新增缺失现代内建 API 的完整页面回归 |
| `Array.at(-1)` 不受支持 | 候选草稿恢复、调度器开始学习有两处不兼容调用 | [useExperience.ts](../src/modes/passage-path/useExperience.ts) 和 [scheduler.ts](../packages/learning-modes/passage-path/scheduler.ts) 使用数组末项下标。新增回归同时覆盖生成、重载恢复草稿和启动八题会话 |
| CSS `max()` 不受支持 | 根容器现代 `padding` 声明被忽略，左右边距实际为 0 | [style.css](../src/modes/passage-path/style.css) 先声明 `20px 16px 48px` 回退，再声明现代布局。既有窄屏/样式隔离测试增加不支持现代声明时的实际样式解析断言 |

修复后模拟器直接确认 `Array.prototype.at` 和 `Promise.allSettled` 均为 `undefined`，`CSS.supports` 对该 `max()` 间距返回 `false`，但模式加载、审核草稿恢复和启动学习均正常。1171px 和 320px 视口的左右边距均为 16px；flex 间距回退生效，子项外边距为 10px，无横向溢出。

## 实际流程与结果

| 流程 | 检查结果 |
|---|---|
| 生成、审核、开放 | 生成 24 道候选；部分审核保存后强制停止应用，重启恢复；逐题审核全部候选，缺音频时不能开放；17 段资源就绪后家长确认开放 |
| 缓存和离线学习 | 清空预览缓存后永久课程音频仍完整；关闭网络后可播放原文与题目音频，五种题型均完成实际提交 |
| 错误与辅助 | 故意答错产生错误反馈和有限补练；查看原文记录辅助，原作答事实不被覆盖；两关最终完成，共 17 条作答、2 条路径完成记录 |
| 冷启动 | 强制停止应用后恢复原题序和反馈；未提交的部分输入 `bas` 保存、退出并重启后恢复，不额外产生作答 |
| 孩子和课程切换 | 第二个孩子从第一关开始；原孩子输入和队列独立。选择没有闯关内容的自建课时显示拦截，不能开始学习；切七步再切回并选回原课，原会话输入逐项一致 |
| 缺少音频与修复 | 删除已开放版本的音频后，提交失败且不增加作答，退出后继续按钮禁用，原文仍可访问；家长重新整理完整音频后原会话及所有进度保持一致并可继续 |
| 重新生成 | 新候选原文确认和逐题审核归零；已开放包、发布指针、所有会话、作答和完成记录逐项不变。再次冷启动后最新候选恢复，旧开放版本仍可继续学习 |
| 视觉检查 | 检查平板主页、审核页、答错反馈，以及 320px 窄屏主页和排序题页面；最终版本无横向溢出和零边距问题 |
