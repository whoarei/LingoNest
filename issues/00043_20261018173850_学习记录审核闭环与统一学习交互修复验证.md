## 本轮变更

| 范围 | 实现及保留边界 |
|---|---|
| 公共学习记录 | 框架显示插件提供的题目、结果、原答案、参考答案、说明和作答条件；闯关还提供原文依据。记录详情可进入模式报告并返回同一详情。七步口语结果读取家长确认后的有效评价，原提交事实保留。框架只展示，不参与判分。 |
| 辅助记录 | 新闯关会话单独保存主动查看提示/原文的条目，同题同类合并为一项；与接触答案后的巩固作答次数分开。区分提交前、提交后查看，提交后查原文不会改写原作答条件。旧会话缺少记录时显示未记录，不回填为零次。 |
| 闯关课程审核 | 完整教材对照；编辑知识块、目标名称和关卡名称；逐题编辑题干、答案、解释、音频文字、原文依据；退回修改；全部/待审核/待修改筛选；审核通过后接下一题；冷启动接第一道未审核题。筛选后的上一题/下一题遵守筛选范围。 |
| 修订与发布 | 内容编辑建立新候选修订，原发布包和历史作答保留。改一题只清除此题审核；改知识块或目标重置相关题目审核，并要求重新确认教材安排。全部题目通过且新修订音频齐备才能发布。发布内容与全局开放模式分别说明。 |
| 统一退出 | 练习中只保留框架的“保存并退出”，Android 返回键使用同一确认框。取消后继续当前题；保存失败停留原位置。完成后直接返回，不再询问是否中断练习。报告、记录详情、内容准备及设置返回各自来源。切换全局模式后返回学习空间。 |
| 统一反馈 | 插件、课程管理、音频面板及模型设置的操作反馈接入框架。成功提示自动消失并允许点击下方控件，错误可关闭。初始化显示忙碌状态，读取失败后仍可进入恢复设置。 |
| 七步播放与权限 | 以原生实际播放开始事件记录接触；播放开始前失败不写提示。原生 TTS 的 playing 事件移到 utterance onStart。孩子端进入学习时刷新课程音频状态。麦克风拒绝说明当前录音无法完成，并提供经家长确认打开系统应用设置的入口。 |
| 完成与输入 | 七步完成页显示本轮通过、待确认、提示练习和家长确认入口，7/7 首页指向复习。闯关显示关卡标题、基础题与补练数量、首答结果、辅助条目、下一关/本课复习。手机提交栏随视口保持可见，补全题支持回车提交，反馈时收起键盘。去除自建课的运动主题阶段文案，明确理解与应用题的计数。 |

## 模拟器实际体验

环境为 `Pindou_8in_Tablet` / Android 10 / API 29 / WebView 74.0.3729.185，使用只读临时会话。平板视口 1171×806；另切换手机视口 412×751，真实软键盘弹出后为 412×456。素材沿用上轮的“体验小树”和“My Family · 体验课”。

### 七步

1. 恢复上轮已完成的课程及记录，首页正确显示 7/7 和“本课练习已完成，去复习”。
2. S4 点击示范，真实原生引擎返回缺少英语音色。接触事件前后均为 18 条，当前轮提示为空；不再误记一次示范。
3. 实际拒绝麦克风；提示说明当前录音无法完成。点击恢复入口，经家长算式确认后打开 `com.android.settings/.applications.InstalledAppDetails`，返回后仍保留练习。
4. 课程管理整理 3/3 段音频后，孩子端直接显示“课程音频 · alloy · 本地长期保存”。实际播放成功才增加 1 条接触事件和对应提示。
5. 独立朗读提交后完成页显示“通过 0、待确认 1、提示 0”。家长确认按钮起初禁用；真实回听本地文件至结束后允许确认。完成页随后更新为“通过 1、待确认 0”，回到路线恢复 7/7。

### 闯关设计与学习

1. 在全局仍为七步时打开闯关内容准备，通篇对照教材。在已发布内容上修改一题说明，建立独立候选修订，原版本、17 条旧作答完全一致；其他 23 题保持审核。
2. 实际退回、筛选、修改及重新审核该题。修改知识块释义和第一关名称后，只清除相关 12 题审核，其余 12 题保留；完整教材确认恢复为未勾选。覆盖安装与冷启动后仍接第一道未审核题。
3. 完成 24/24 审核，整理 2/2 音频并发布。页面明确“当前开放模式：七步学习”；通过统一设置切到闯关后，孩子端才进入闯关。
4. 第一关主动查一次原文，再故意选错。立即显示“8 道基础题 · 1 道补练”和补练原因。完成后为首答 7/8、补练 1、主动辅助 1 项，直接进入第二关。
5. 第二关首答 8/8、补练 0；完成后按钮为“复习本课”。首页 2/2 后同样显示复习入口。两关新增 17 条作答，覆盖选择、补全及排序。
6. 手机真实键盘下，提交按钮底部位于 CSS y=422，小于视口高 456，可见且可点击。使用 `adb input text` 输入、系统回车提交成功，反馈后视口回到 751。保存未提交的 `fam`，冷启动后同一会话与输入完全恢复。
7. 按 Android 返回键出现与页面退出相同的确认框；取消保留输入。错题详情准确显示错误选项、参考答案、原文和修订说明；报告将主动辅助 1 项与巩固作答 15 次分别展示，返回仍在同一作答详情。
8. 新开复习并独立提交，退出后从“课文原文”查看教材。记录准确显示“提交前未使用辅助；提交后主动查看原文”，原提交 assisted 仍为 false。
9. 闯关→七步→闯关，两个模式数据快照逐字相同，待处理反馈完整恢复；从内容准备进入设置切换模式后，Android 返回正确进入学习空间。

## 验证边界

本轮审核修订使用上轮固定测试题库，没有据此验收模型生成质量、拍照/OCR 或真人教学效果。音频为本地合成测试文件，课程音频整理、保存、播放均走真实原生实现。口语成功分支替换录音采集返回值，随后真实保存、播放并由家长确认；麦克风拒绝及设置跳转为真实操作，真人采集质量仍须在可用麦克风环境验收。

代码和报告保留在当前工作区，未提交 Git。
