# 闯关课程梯度重练与变式轮换优化验证

建立时间：2026-10-24 17:31:20（Asia/Shanghai）。在上一轮未提交的闯关复审工作区上继续优化，保留此前全部变更。设计与官方参考资料见[课程优化设计](../docs/00028_20261024173120_借鉴多邻国的闯关课程优化设计.md)。

## 复现与修复

| 问题 | 复现 | 修复 |
| --- | --- | --- |
| 新目标的填空可能在组句前 | 单目标 seed 5、双目标 seed 0 可复现 | 在已选的同目标任务间建立理解、组句、回想的前置关系 |
| 重练仍被视为首次教学 | 已完成关卡重练先出现理解题；隔天仍难积累回想证据 | 按本人准确版本的实际接触情况区分新目标与复习目标，重练优先独立题 |
| 跨轮立即重复同一变式 | seed 0 的旧目标回访再次抽中先前回想题 | 同难度候选优先未练，再按最久未练轮换，随机种子处理并列 |
| 最终乱序破坏变式优先级 | 所有变式均已练后，较新的回想题可能被排到最旧题前 | 固定各旧目标本轮首次独立题，其余题目继续交错 |

新增回归先复现前三项失败；扩展最久未练轮换时继续发现并修复最终乱序的问题。部分接触后重新开始的回归验证：旧目标独立复习，新目标仍获得逐步支持；课程未被误判为全部已学。另验证其他孩子不影响本人的选题、时钟回拨不改变题目新旧排序，以及已保存的调度版本 2／3 原样恢复。

页面回归走完一轮后从路径点击“重练”，确认首题直接独立填空，提交保留 `assisted: false` 和 `evidenceEligible: true`。跨日间隔是否合格由独立证据投影继续判断，页面测试不把一次合格作答等同于稳定掌握。
