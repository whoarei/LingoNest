# 闯关多次短课、听说与结算循环审查验证

建立时间：2026-10-24 19:18:49（Asia/Shanghai）。范围是落实[课程优化设计](../docs/00028_20261024173120_借鉴多邻国的闯关课程优化设计.md)中的多次短课、情境迁移、听说练习和结算建议，并反复检查交互、学习证据、架构及隔离恢复。最终行为见[实施设计](../docs/00029_20261024191849_闯关多次短课情境迁移与听说闭环设计.md)。本报告与上一轮调度版本 `4` 的[验证](00051_20261024173120_闯关课程梯度重练与变式轮换优化验证.md)分别归档。

## 实现与循环修复

| 检查轮次 | 发现与处理 | 验证依据 |
| --- | --- | --- |
| 课程组织 | 单轮完成无法表达同一目标多次接触；增加初识、迁移、听说三次短课，全部完成才通关 | 多目标、不同种子、4～6 题预算与冻结会话恢复 |
| 内容准备 | 原题库没有明确的新情境、口语参考或各短课覆盖保证；增加结构、生成要求、编译校验与家长分组审核 | 缺失情境／听辨／口语时拒绝编译；真实页面生成和完整审核 |
| 学习证据 | 口语自评不能当作答对；引入未判分作答，排除答对率及稳定证据 | `correct: null`、自评再练建议与无无限补练 |
| 听辨与回听 | 停止播放也可能被误当听完；仅完整且仍属于当前题目的播放保存完成事实 | 停止后不能提交、回听后才能自评、重载恢复 |
| 数据与删除 | 重录替换后旧文件可能脱离引用；会话保存全部录音资源，接入现有删除协调器 | 两课两孩子隔离、归档恢复、清理失败后重启重试，七步原始数据保持一致 |
| 权限与保存 | 权限拒绝后的全局错误提示可能残留；恢复成功显示明确状态，失败保留自评供重试 | 拒绝、家长设置、重新录音、回听中断和自评保存失败浏览器场景 |
| 自动保存恢复 | 先复现“自评保存失败→改选并自动保存成功”后旧错误仍留在框架；恢复成功时通知框架当前作答已保存 | 扩展原口语浏览器场景，核对真实持久输入与全局错误同时恢复 |
| 异步边界 | 原录音作用域未包含工作区激活状态；补充可见性、入口和激活代次校验，失效时取消自身录音 | 类型检查、现有工作区往返与播放取消回归；不接管其他模式音频 |
| 辅助归因 | 当前口语题期间其他播放也会被记成提示；限定准确来源的本题示范，并单独记录“示范” | 示范辅助持久化及口语提交回归，框架契约未扩展 |
| 隔天复习 | 重练初识后，旧目标的情境题可能作为到期题进入新初识短课，违反基础题校验 | 先复现失败，再限制同课程复习题类型；20 种子回归通过 |
| 家长编辑 | 增加情境与回听要点编辑、预览和发布隔离检查；首次新增测试未先生成候选，修正测试前置条件 | 从真实生成入口开始，编辑建立新修订、不改发布和孩子进度 |
| 小屏交互 | 新增单选自评控件受到原通用输入样式影响；补充局部样式，口语报告支持分页回听 | 320／390 像素截图复核及无水平溢出断言 |

结算推荐最多两个目标，提供继续、休息或一次巩固的明确选择。隔天回访按当前孩子、课程及修订读取，完成后不会立即再次推荐；重练不增加通关数。旧发布课程维持自身规则，新生成才启用三次短课，避免错误重解释历史。

## 自动化与复核

完整回归通过 26 个单元测试文件、249 项测试及 96 项 Microsoft Edge 浏览器测试。完整回归后增加自动保存恢复场景并修复提示残留，再对闯关课程、原有闯关与交互修复页面复跑 22 项浏览器测试，全部通过；末次生产构建与类型检查通过，构建前后均确认没有预打包课程音频。81 份归档 Markdown 的编号与相对链接检查通过，已有变更和新增文本文件的空白检查通过。验证入口：

- `tests/passage-curriculum.test.ts`：多目标覆盖、三次短课、口语证据、隔天建议、准确录音归属与跨短课复习。
- `tests/passage-curriculum-storage.test.ts`：真实服务和存储、重录资源、归档恢复、彻底删除失败与重启续作。
- `tests/e2e/passage-curriculum.spec.ts`：五个完整页面场景，包括学习、取消播放、权限和保存恢复、家长审核编辑、隔天回访。
- 既有闯关、公共目录、七步、跨模式导航和旧 WebView API 回归。
