# 七步模式独立化重构与兼容验证

建立时间：2026-10-15 16:24:14（Asia/Shanghai）。基线为应用 `0.1.14`，对应[首阶段实施说明](../docs/00018_20261015162414_七步教学模式独立化首阶段实施说明.md)。

## 1. 调整内容

将七步模式的模型、教材、生成提示、课程编译、评分/证据/复习、快照校验、课程删除与报告移到 `packages/learning-modes/seven-step/`。学习页面、家长准备和审核页面、运行组合函数与样式移到 `src/modes/seven-step/`。

新增不约束阶段和题型的模式契约、注册表及宿主，应用入口通过懒加载模式体验启动。快照读写、内容服务传输及语音控制抽为公共能力；原导入路径保留兼容出口。清理模式作用域时移除已完成或迟到注册的原生监听，避免已卸载实例继续接收事件。

## 2. 兼容验证依据

- 重构前捕获的[旧版样本](../tests/fixtures/seven-step-legacy.json)固定记录内置教材/题库、课程音频、自建课程编译包及学习投影摘要。
- [模式兼容测试](../tests/teaching-modes.test.ts)逐一对比上述摘要，并加载旧自建课程、确认记录、两份档案和未完成练习。旧快照仍需遵守原有前置阶段条件，满足后恢复原答案和提示状态。
- 现有课程、引擎、运行和音频测试继续通过历史入口执行，保证兼容出口和新实际实现使用同一套数据与函数。
- 新增模块边界检查：七步核心不得依赖 Vue 或应用基础设施；公共契约、宿主和共享控件不得依赖七步类型和阶段判断。
- 以不同载荷的测试 codec 验证公共仓储只负责保存机制；未知格式读取失败后不能用空数据覆盖原记录。

首轮端到端回归 28 项通过，音频暂停/重载/继续用例发现测试 helper 在模式懒加载完成前调用 `.count()`，误判无需切换家长空间。已改为先等待可见入口，再判断所在空间，保留实际业务操作与原断言；最终复跑结果见上表。

端到端夹具只替换公共内容传输，七步模式使用实际提示词；测试服务把提示请求映射成确定性响应。覆盖生成失败、停止和迟到结果，避免把提示词或编译逻辑在夹具中一并替换掉。

查看了最终[学习首页](../artifacts/screenshots/home-mobile.png)与[家长空间](../artifacts/screenshots/parent-overview-mobile.png)截图：模式样式正常加载，页面结构、导航和学习/家长入口完整。原有端到端用例也检查了窄屏无水平溢出。

## 4. 验证边界

本轮未改变 Android Java、SQLite 格式、课程/题目/资源标识、评分或学习证据规则，未调用真实 OCR、内容生成和 TTS 服务，未构建并安装新的 APK，也未清除或迁移手机数据。浏览器夹具覆盖原生桥接行为，不能声称已完成手机升级验证。

当前注册的模式只有七步，未知模式严格拒绝。其他模式的全局选择、课程内多模式载荷和正式存储迁移仍按架构方案后续实施，本轮不把新的 mode ID 写入旧学习事实。
