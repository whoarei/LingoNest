## 2. 家长确认

[ParentModeSettings.vue](../src/components/ParentModeSettings.vue) 保留待执行动作，仅在答案为 `12` 且动作存在时调用。执行前先清除待执行动作；取消操作直接清除，重新选择时重置答案。返回离开设置会卸载该组件，丢弃未确认动作。原 [CourseModeSettings.vue](../src/components/CourseModeSettings.vue) 对重复选择当前模式继续保持无写入。

补充浏览器探针验证了：

- 从学习空间打开设置，选择测试第二模式，错误答案不能确认。
- 即使直接派发提交事件，错误答案也不会改写模式设置。
- 取消确认、带着待确认动作返回学习空间，再次进入设置，都不会残留或执行旧动作。
- 课程编辑 → 设置 → 选择模式但不确认 → 系统返回，恢复原编辑器；再次进入设置无待确认动作。

这些检查验证的是现有防误触家长确认机制，不代表新增了身份认证。

## 3. 切换前保存与卸载

进入设置时，父级家长空间保留挂载，原 [CourseManager.vue](../src/modes/seven-step/components/CourseManager.vue) 仅变为不可见，编辑课程 ID 未清空。其切换准备函数因此仍在全局准备集合中。

实际确认切换后，先等待七步学习准备和课程编辑器保存，再持久化全局选择并卸载旧体验。保存失败或尚未完成时，不先更新模式。已保存标记继续避免编辑器卸载时追加重复保存。

正式端到端测试覆盖保存失败后的模式拦截、返回后编辑内容保留、重试与往返；补充探针进一步挂起“实际模式切换中的编辑器保存”，确认全局忙状态可阻止系统返回，设置选择仍为七步。随后模拟延迟保存失败，旧模式与编辑器均保留，返回原编辑器后标题保持不变。
