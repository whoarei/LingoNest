## 第一轮：导航、历史和保存

| 问题与触发场景 | 修改 |
| --- | --- |
| 家长打开已删除列表后回到孩子空间，课程列表仍显示已删除课程，点击后报错 | 已删除筛选只在家长空间生效；离开家长空间、恢复或彻底删除最后一门归档课程时重置筛选 |
| 孩子阅读教材后按 Android 返回进入学习记录，页面按钮却返回课程列表 | 两种返回方式统一回到课程列表 |
| 超过 100 条作答时，较早的记录没有查看入口 | 每页显示 50 条，提供前后翻页与总数；改变孩子或筛选后回到第一页；详情返回保留页码；时间补充年份 |
| 学习退出保存中仍能再次点击退出、继续或操作下层内容 | 退出期间防止重复执行，保留失败重试；退出弹框禁用下层控件 |
| 原测试在点击后立即读取存储，或在失败请求完成前解除故障注入 | 等待实际保存结果、失败提示或目标页面；保留失败时不丢草稿的断言 |

验证：新增三个场景用例在修复前均失败；修复后与保存、词汇、系统返回的相关 7 项用例全部通过，类型检查通过。测试文件为 [review-regressions.spec.ts](../tests/e2e/review-regressions.spec.ts)。

## 第二轮：小屏、弹层和编辑反馈

- 100 字符的连续英文标题在 320px 屏幕下造成横向溢出，课程列表还会裁切文字。标题和列表现在可以断行；手机学习页标题最多显示三行，完整标题可在课程页查看；长昵称收起为省略显示，保留完整名称。
- 家长确认、学习退出、删除确认和教材原图建立键盘焦点范围，支持 Escape 取消并返回触发按钮；保存或删除执行时不允许通过 Escape 中断。
- 在 320×280 的软键盘压缩视口中，原确认框顶部为负坐标。现在弹框高度受可视区域限制，内容过长时在弹框内滚动。
- 教材保存后继续编辑，不再保留误导性的“教材已保存”，改为明确提示尚有未保存内容以及离页自动保存。

验证：前三个问题在修复前分别复现；修复后 4 项界面场景检查全部通过，类型检查及差异空白检查通过。检查了 320px 和 390px 的长标题截图。见 [review-usability.spec.ts](../tests/e2e/review-usability.spec.ts)。
