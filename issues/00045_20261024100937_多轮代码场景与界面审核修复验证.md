## 第一轮：导航、历史和保存

| 问题与触发场景 | 修改 |
| --- | --- |
| 家长打开已删除列表后回到孩子空间，课程列表仍显示已删除课程，点击后报错 | 已删除筛选只在家长空间生效；离开家长空间、恢复或彻底删除最后一门归档课程时重置筛选 |
| 孩子阅读教材后按 Android 返回进入学习记录，页面按钮却返回课程列表 | 两种返回方式统一回到课程列表 |
| 超过 100 条作答时，较早的记录没有查看入口 | 每页显示 50 条，提供前后翻页与总数；改变孩子或筛选后回到第一页；详情返回保留页码；时间补充年份 |
| 学习退出保存中仍能再次点击退出、继续或操作下层内容 | 退出期间防止重复执行，保留失败重试；退出弹框禁用下层控件 |
| 原测试在点击后立即读取存储，或在失败请求完成前解除故障注入 | 等待实际保存结果、失败提示或目标页面；保留失败时不丢草稿的断言 |

验证：新增三个场景用例在修复前均失败；修复后与保存、词汇、系统返回的相关 7 项用例全部通过，类型检查通过。测试文件为 [review-regressions.spec.ts](../tests/e2e/review-regressions.spec.ts)。

## 第二轮：小屏、弹层和编辑反馈

- 100 字符的连续英文标题在 320px 屏幕下造成横向溢出，课程列表还会裁切文字。标题和列表现在可以断行；手机学习页标题最多显示三行，完整标题可在课程页查看；长昵称收起为省略显示，保留完整名称。
- 收尾检查为共享标题、列表、原文及作答详情补充 `break-word` 断行回退，保留不支持 `anywhere` 的视图引擎的断行行为。
- 家长确认、学习退出、删除确认和教材原图建立键盘焦点范围，支持 Escape 取消并返回触发按钮；保存或删除执行时不允许通过 Escape 中断。
- 在模拟软键盘压缩后的 320×280 视口中，原确认框顶部为负坐标。现在弹框高度受可视区域限制，内容过长时在弹框内滚动。
- 教材保存后继续编辑，不再保留误导性的“教材已保存”，改为明确提示尚有未保存内容以及离页自动保存。

验证：前三个问题在修复前分别复现；修复后 4 项界面场景检查全部通过，类型检查及差异空白检查通过。检查了 320px 和 390px 的长标题截图。见 [review-usability.spec.ts](../tests/e2e/review-usability.spec.ts)。

## 第三轮：实际场景与文档一致性

- 闯关未提交答案时出现错误，家长进入设置后再返回，原实现无条件清空会话绑定，显示“请重新进入学习”。现在仅在孩子、课程或发布版本不再匹配原会话时解除绑定，同一上下文保留当前题目与未提交输入。
- 复审补充了跨课内容更新导致会话停用的边界：停用会话回到学习路线，保留旧会话事实，再开始时建立新会话。停用状态通过存储夹具模拟，未把它记为实际设备发布测试。
- 连续两次遇到相同自动保存错误，原来的模式错误值没有重置，第二次可能不再通知框架。新一轮输入先重置错误，失败时重新显示提示；扩展的设置往返用例覆盖连续失败、恢复和停用后的重新开始。
- 新建教材但未填写就返回，原实现进入没有课程的空详情。现在直接回到课程列表，不制造空白教材；正常编辑过的草稿仍在离页时保存。
- 两个场景在修改前复现、修复后通过，包含系统返回和页面返回。见 [review-scenarios.spec.ts](../tests/e2e/review-scenarios.spec.ts)。
- 架构文档中“当前问题”实际描述的是重构前代码，已明确历史背景；新增[当前实现与开发验证指南](../docs/00023_20261024101255_当前实现与开发验证指南.md)，说明真实使用流程、教材只读边界、现有注册契约、兼容存储和验证方法。增加 `npm run check:docs` 入口。

完整回归还发现短轮开始、审核通过、恢复输入等旧测试会抢在异步提交前读取存储或探测控件；补充等待页面进入相应状态，保留原有数据、审核和禁止重复作答的检查。
