# 图库图片不可读取修复与验证

建立时间：2026-10-15 10:24:06（Asia/Shanghai）。对应版本：0.1.9 / versionCode 10。

## 问题与原因

真机从图库导入课文图片后，缩略图显示“图片不可读取，请重新添加”。这条提示来自 `SourceImages.vue` 调用 `imageSource()` 失败；与导入本身失败时显示的“图片无法读取或超过 20 MB”不同。

源码检查发现，`CourseContentPlugin.imageFile()` 直接比较图片的绝对路径和规范路径。如果系统提供的应用私有目录含路径别名，例如 Android 的 `/data/data` 与 `/data/user/0`，即使导入已经成功、图片确实存在，这两个路径仍可能不同，原校验会拒绝预览和识别读取。这是已确认的代码缺陷；由于本轮未连接到用户手机，尚未获取该设备的实际目录路径以闭环确认。

## 修复

- 图片读取统一调用已有的 `NativeGuards.courseImageFile()`，先规范化可信的应用私有根目录，再验证图片路径。
- 保留 `course-images/` 相对路径格式、图片目录与文件符号链接拒绝、文件存在检查；预览与模型识别共用该读取入口。
- 图片引用格式和已保存文件不变，已有图片无需迁移，重新进入课程时会重新读取。
- 更新版本为 0.1.9 / versionCode 10，方便区分修复安装包。
