# 闯关模式交互学习与架构循环审查修复验证

建立时间：2026-10-24 17:06:54（Asia/Shanghai）。本轮基于 `46c6dc0`，重点审查课文闯关的孩子交互、学习证据、家长内容准备与模式边界。设计见[当前闯关设计](../docs/00027_20261024170654_闯关课程学习交互与证据边界设计.md)。验证以本轮结束时的代码为准。

## 问题、影响与修复

| 问题 | 可观察影响 | 修复 |
| --- | --- | --- |
| 提示把整轮多个目标都标成受辅助 | 当前目标求助会排除无关目标的独立证据，跨课记录也受到污染 | 提示只影响同课程、修订与当前目标；原文只影响实际显示来源 |
| 旧目标的复习可能先给选项、组句或答案 | 需要回想的目标在同轮后续回答前已经被反馈暴露，难以积累独立证据 | 已学目标优先选择独立题，在同目标支架与反馈前回答；覆盖过的目标不再重复占复习名额 |
| 暂停在跨课题后阅读本课时记错来源 | 显示本课原文却把跨课目标标成受到辅助 | 显式传入显示来源；整课阅读单独记录，不伪造某题的查看时点 |
| 教材更新后仍加载旧候选 | 修改审核状态后保存被来源校验拒绝，再生成又先保存旧草稿，形成死路 | 完整来源匹配后才能恢复候选；旧数据保留，新教材可直接重新生成 |
| 过期候选仍显示为待审核 | 首页与课程管理提示和实际准备页不一致，历史资源也混称候选 | 状态统一筛选有效来源；只取每课最新有效候选计算待审核，避免发布后旧候选持续制造待办；资源区分历史及过期 |
| 审核勾选后的保存状态不可见 | 家长无法分辨勾选是否已落盘 | 反应式脏状态提示，保存检查点与正常离页保存同步 |
| 交卷后焦点停留在禁用控件或页面主体 | 键盘用户不易找到反馈与下一题；旧提交回调还会清除新焦点 | 提交、继续与结算分别聚焦；删除迟到的无条件 blur，输入保存不抢焦点，退出恢复及收起原文重新定位 |
| 填空允许超过核心长度限制 | 长文本粘贴后自动保存、提交和退出都可能被拒绝 | 输入长度与核心 2000 字符上限一致 |
| 孩子朗读没有停止入口 | 播放期间其他操作被锁住，长段音频无法主动中断 | 增加视口底部停止控制；滚到原文末尾也能操作；取消不报失败 |
| 每次交卷检查全部课程音频 | 桥接调用和控制器创建随无关课程增长，混入其他孩子的资源检查 | 提取纯范围计算，活跃轮只检查其队列与主课，新轮只扩展当前孩子的已学可用版本 |

## 审查与修复循环

1. 静态检查纯运行器、调度、证据投影及来源引用；用多种随机种子复现回想题被同目标反馈提前暴露，修正选择与顺序。
2. 检查孩子求助与跨课混练，新增提示／原文范围和整课阅读来源回归；校验快照往返与历史队列保持。
3. 检查内容生成、审核、保存、教材更新和再次生成；补完整浏览器操作复现，保留旧候选后验证生成不再被旧草稿阻塞。
4. 检查键盘、输入长度、音频中断和资源范围；修正提交后的焦点竞争，并在长原文末尾验证停止入口仍位于视口中。
5. 复审候选状态投影及资源清单，补来源变化后的概况回归；抽出教材纯适配，避免概况依赖保存、删除与运行服务。
6. 完整回归后继续复查恢复焦点与候选发布。补回归复现发布最新候选后旧候选仍让课程持续待审核，修正每课只取最新有效候选；同时修复退出再恢复同题不重新定位、收起原文丢焦点，重新执行受影响场景与完整回归。

## 范围与结论

最终再次检查题序与必要覆盖、独立证据、提示和原文的准确来源、候选失效与发布、音频归属与范围、键盘和小屏，以及公共框架与两个独立教学核心的职责。保留现有分层结构合理；本轮修复都留在闯关模式及其教材适配边界，未向框架加入闯关教学规则。上述范围内未再发现值得修复的问题。

本轮没有修改 Android 原生代码。浏览器场景使用 Edge 加受控原生接口夹具；独立证据回归验证的是规则一致性，不能代替儿童试用、真实模型题库质量、真机音频及长期学习效果验收。
