# 全局课程模式实现与兼容验证

建立时间：2026-10-16 10:06:13（Asia/Shanghai）。设计说明见[全局课程模式选择与存储隔离](../docs/00019_20261016100613_全局课程模式选择与存储隔离.md)。

## 1. 实现范围

家长空间新增“模式”导航及概览入口；设置只保存一个本机全局模式，覆盖所有课程和档案。正式注册表只有七步学习，第二模式仅在测试中注册。切换执行家长确认、停止媒体、保存恢复点及独立设置提交；失败不卸载旧模式。

增加通用课程发布就绪检查与生成审核提示。七步学习入口拒绝使用其他模式的内容；旧七步已发布课程继续开放，无需重生成。新的 Android 文档接口使用独立数据库；七步原库和历史快照结构保留。

## 3. 执行结果

- `npm test`：11 个文件、100 项通过（含原有 90 项）。
- `npm run test:e2e`：37 项完整回归通过（含原有 33 项）。
- `npm run build`：类型检查与生产构建通过，未捆绑预生成课程音频。生产产物仅包含七步体验及公共宿主。
- `android/gradlew.bat testDebugUnitTest --console=plain`：通过，包含新的原生文档命名测试；原生插件新增方法编译通过。
- `node scripts/check-doc-links.mjs`：45 份归档 Markdown 编号、相对链接有效。

最后的窄屏检查复现了新增第五个导航项在 320px 宽度下超出屏幕 11px 的问题；已让家长导航按钮均分可用宽度，孩子导航不受影响。随后模式切换和样式隔离的 8 项针对回归全部通过，并检查了 320/1280px 页面截图；截图位于本机忽略目录 `artifacts/global-course-mode-320.png` 与 `artifacts/global-course-mode-1280.png`。

## 4. 数据兼容结论与验证边界

全局初始化和无练习切换不改变旧七步快照字节。练习中切换只更新所属恢复点，既有课程和事件不变；进度保存失败不会提交模式选择。旧课程编译包、音频规格、学习投影及历史记录继续通过固定样本验证。

本次未升级手机安装、未运行会清空应用数据的设备测试。Android 数据隔离由仓储接口测试、数据库命名测试和原生编译验证；实际覆盖安装后的文件级兼容性仍需新包真机验证，不能引用[此前安装验证](00025_20261016094238_七步模式重构真机覆盖安装验证.md)作为本次新增功能的安装结果。
