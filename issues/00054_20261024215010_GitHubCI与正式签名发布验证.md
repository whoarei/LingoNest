## 签名转存

源仓库已有四项签名 Secrets，GitHub 不提供明文读取接口。在源仓库临时增加仅手动触发的工作流，将四项值使用目标仓库公钥与 libsodium sealed box 加密，下载的中间产物只包含密文，再通过 Secrets API 写入 LingoNest。

[签名转存运行](https://github.com/whoarei/peerlink/actions/runs/40099963206)已完成加密及 keystore 证书验证，四项目标 Secrets 已创建。转存工作流完成后移除，密文中间产物清理；源仓库原签名 Secrets 未改动。本地 PeerLink 工作区未改动。

发布证书 SHA-256：`28c461e4f2f8612f9d7717d727e772177474798fd7c48b03ca3ffbca8c81bf0a`。此前本地 Debug 证书为 `358e059e7f74fbf5fcfe98a5ccb4b7b519dfdbaf271e204289f6663889d17e97`，两者不同，版本说明已明确旧 Debug 安装不能覆盖升级及卸载的数据影响。本轮不操作用户设备。
