## 实现范围

- 顶部公共菜单与独立更新页面，保留家长设置权限。启动网络检查不阻塞应用初始化；练习中不提示，退出后再提醒。
- 24 小时自动检查节流、失败后 15 分钟退避、构建号对应的“稍后”抑制、手动检查、下载进度、取消和重试。
- 原生下载与缓存校验，限制 HTTPS／GitHub 来源、大小、包身份、版本、兼容性和正式证书；拒绝旧版本与测试签名安装。
- 安装前保存，系统安装来源授权及再次主动安装，未完成安装不显示成功。
- GitHub CI 自动生成并发布 `update.json`，校验文件包含清单。未修改签名密钥、版本号或已公开的 Release。

## 发布与实测边界

本轮完成源码与工作流修改和本地验证，未提交、推送、打标签或触发 GitHub 发布。现有公开 `0.1.16` 资源没有 `update.json`，因此真实线上更新链路需在携带本功能的新正式签名版本发布后，再验证“旧正式版 → 新正式版”的系统安装和数据保留。

本机 Debug APK 故意不能走正式签名在线更新。APK 签名的完整验证由 Android 系统执行，原生单元测试不冒充系统安装器实测；实际网络可达性、不同厂商安装来源设置以及覆盖升级后的学习数据，需要正式签名设备验收。
