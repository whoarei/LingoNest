# 全局模式切换两项 P2 修复验证

建立时间：2026-10-16 10:54:37（Asia/Shanghai）。对应[全局课程模式切换实现审查](00027_20261016102755_全局课程模式切换实现审查.md)中的两项 P2。

## 1. 修复结果

### 旧恢复点被写成空答案

[useLearning.ts](../src/modes/seven-step/useLearning.ts) 使用可为空的活跃 `sessionId`；清空当前练习时立即解绑该标识。恢复点查找必须有有效题队列，并匹配当前孩子与课程。模式切换只保存确实仍绑定的活跃会话，不向已退出的历史会话写入空答案、空选项或空录音路径。

原有恢复点、课程包、评分与事件结构未迁移。切回七步后仍从旧恢复点恢复文本、已选选项和提示状态。

### 模式页提前卸载编辑器

[CourseManager.vue](../src/modes/seven-step/components/CourseManager.vue) 暴露可等待的 `prepareLeave()`，与模式切换准备函数复用停止媒体、检查任务状态和保存草稿逻辑。保存期间若有新修改，继续保存最新草稿，直到版本稳定；成功后标记已准备离开，卸载时不重复保存。

[Experience.vue](../src/modes/seven-step/Experience.vue) 在切换页签或退出家长空间前等待离开检查。只有成功后才清空编辑课程 ID、更新页签和卸载编辑器。家长页签采用受控传值，来自 [ParentSpace.vue](../src/modes/seven-step/components/ParentSpace.vue) 内部的导航请求同样经过检查，避免绕过。等待期间拒绝其他导航和系统返回，保存失败留在原页面，修改可继续编辑或重试。

未关闭编辑器的设置页面仍保留原来的往返行为；课程处理或音频生成尚未完成时会提示先完成或暂停。
