在最终调试 APK 上另运行 [smoke-android.mjs](../scripts/smoke-android.mjs)，通过 WebView 调试接口驱动实际应用页面与原生插件，确认：

1. Chrome/WebView 74 可加载生产构建，界面能够创建昵称档案。
2. 通过界面提交的选择题写入原生 SQLite。
3. 强制停止并重新启动后，档案、作答、当前题目及反馈均保留。

6. 原生麦克风可启动，模拟器输入为静音，停止时返回 `RECORDING_SILENT`，不产生有效待复核成绩。此项**不表示真人语音采集及完整回放已实测**。
7. 删除本次测试档案后，学习事件与录音清理任务归零；其他档案不会被测试脚本清理。脚本要求专用空白测试安装，遇到既有档案即停止。

浏览器图形检查覆盖 390×844 与 1280×900。Android 截图为 2048×1536 平板环境，确认主要布局、文字、操作区和系统栏无明显遮挡。

## 3. 实测发现并修复的问题

- **句子阈值单位不一致**：将课程阈值统一为 90/100，避免 0.9 被误读成 100 分制；按词/字符 7:2 权重计算，并用无关答案与否定词反例验证。
- **能力归因混淆**：排序与独立书写拆为不同模式；补足真实题族，使正常跨日复习可达到独立性要求。
- **答案暴露与中断恢复**：课文、提示、参考文字先保存暴露，再展示；保存提示级别和当前轮次，重启不能绕过提示标记。未测目标不会因看课文自动产生到期任务。
- **并发操作**：提交和下一题增加立即生效的互斥保护，防止重复事件或连续点击跳题；持久化先成功才发布新状态。
- **档案删除**：将录音清理写入可恢复待办，原生删除失败时保留重试，应用下次启动继续处理。
- **SQLite API 29 兼容性**：`PRAGMA busy_timeout` 改为查询读取；大快照分块读取，避免 CursorWindow 截断；损坏数据库不静默重建。
- **原生录音质量**：检查时长和声音能量，拒绝静音、过短、截断、后台中断的录音；回放必须完整结束才允许 UI 标记“已回听”。
- **旧模拟器 GPU 字体崩溃**：实测出现 `Chrome_InProcGp / SkGlyph / Unknown mask format`，只对 API 29 + ranchu/goldfish 模拟器 + WebView 74 启用软件层。最终 APK 已重新完成界面及恢复流程；不改变模拟器全局配置，真实设备维持正常渲染。
- **学习快照日志**：关闭 Capacitor `loggingBehavior`，避免调试桥打印答题内容。
- **Windows 构建兼容性**：产物摘要改用 .NET SHA-256，避免旧 PowerShell 环境缺少 `Get-FileHash` 导致 APK 已生成但归档脚本失败。
