## 1. 本次改动

原先朗读仅依赖设备离线 TTS，音色固定。本次在家长空间加入服务配置、内置/自定义音色、语速、风格、保存并试听、取消/停止、配置删除和音频缓存清理；课文与练习示范统一使用所选方式。

支持 OpenAI /audio/speech 和 MiMo 的专用聊天消息语音合成协议。AI 语速由原生播放器调整，缓存不因变速失效。Key 单独保存在 AndroidKeyStore 保护的加密配置中，学习快照格式、教材内容版本和既有事件不变。

## 3. 尚未执行的设备验证

本轮原物理设备 172.16.0.16:5555 的无线 ADB 持续显示 offline，重连没有恢复。此前该设备安装的是 0.1.1；本次没有报告为已更新 0.1.2，也没有导入实际 Key。API 29 模拟器尝试启动后退出，未形成可执行设备测试的环境。

新增 [SpeechIntegrationTest.java](../android/app/src/androidTest/java/cn/lingonest/app/SpeechIntegrationTest.java) 已编译，4 个测试仍待设备执行：AndroidKeyStore 配置持久化/无明文、换服务不能复用旧 Key、实际音频验证与缓存重启复用、非音频与取消输出不入缓存。测试使用随机隔离的 prefs、Keystore alias 和缓存沙箱，不接触既有学习数据库。

恢复连接后，采用保留数据的 APK 覆盖安装，再手动安装“测试 APK”并指定语音测试类执行：

~~~powershell
E:/Android/sdk/platform-tools/adb.exe install -r artifacts/lingonest-0.1.2-debug.apk
E:/Android/sdk/platform-tools/adb.exe install -r android/app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
E:/Android/sdk/platform-tools/adb.exe shell am instrument -w -e class cn.lingonest.app.SpeechIntegrationTest cn.lingonest.app.test/androidx.test.runner.AndroidJUnitRunner
node scripts/configure-speech-android.mjs --verify
~~~

对已有用户数据的手机不使用 Gradle connectedDebugAndroidTest 的安装/卸载生命周期。上述步骤不清空或卸载主应用，之后仍需实际回听试听音色、慢放音质以及后台/耳机中断流程。
