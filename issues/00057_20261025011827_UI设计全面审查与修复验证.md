# UI 设计全面审查与修复验证

建立时间：2026-10-25 01:18:27（Asia/Shanghai）。

## 结论

应用的暖白、深绿、圆角卡片和小鸟插画符合“英语小窝”的学习场景，应继续沿用。主要问题集中在公共框架与教学模式的样式衔接、操作层级、文字可读性和浮层遮挡，而不是需要重新设计品牌。

本次直接修复了下列问题，并通过浏览器实际渲染、截图和交互回归验证。检查覆盖孩子学习空间、七步路线与课文阅读、闯关路径与答题、课程列表与教材编辑、家长概况、设置，以及既有课程审核、录音确认和退出保存流程。浏览器测试使用隔离数据及受控原生接口；截图不代表 Android 真机验收。

## 问题与修复

| 维度 | 原有问题与影响 | 修复结果 |
| --- | --- | --- |
| 导航与页面骨架 | 短课程列表、少量学习记录的底部导航出现在页面中段，下面留下无意义空白 | 应用采用纵向弹性布局，内容区撑满剩余视口；短页导航贴底，长页继续吸底 |
| 内容对齐 | 公共页面、七步和闯关工作区的最大宽度、桌面左右留白不同，切换页面时内容边缘跳动 | 统一使用最大 1044px 的内容容器、桌面 28px 和手机 16px 的水平内边距 |
| 操作层级 | 公共样式直接覆盖几乎所有按钮，导致“返回”成为实心按钮、两种模式都显示深绿色、语音预设和试听操作缺少次要层级 | 移除泛化按钮覆盖，只给明确的按钮类赋样式；主操作实心、次要操作描边、返回使用文字链接；教材拍照、选图等操作显式标记为次要按钮 |
| 长设置页的信息组织 | 语音、识别、生成配置缺少稳定的区块样式，图标与标题分离，配置表单和按钮相互粘连 | 设置分成独立卡片，增加“课程模式／语音与朗读／识别与生成／数据维护”跳转；模型配置桌面双列、手机单列；恢复标题、帮助文字和按钮间距 |
| 家长概况的信息密度 | 三项概要在手机上各占一整行，主要管理入口被推到首屏末尾 | 当前模式单独一行，课程数与记录数并列，保留完整标签与数值，减少无效垂直空间 |
| 模式和语速选择 | 当前模式的视觉选中状态被公共样式覆盖；语速预设没有持续的选中反馈；模式单选组只有点击行为 | 模式采用稳定的双像素边框、浅绿背景和“当前开放”文字；语速增加 `aria-pressed` 与选中样式；模式支持方向键、Home、End 和单一 Tab 入口，切换后恢复焦点 |
| 学习文字可读性 | 七步课文译文、说话人、题目辅助说明、选项字母及提示颜色过浅；部分步骤说明只有 10–11px | 加深辅助文字、头像字母、状态标签和提示颜色；步骤说明至少 12px，手机译文 13px、说话人 12px，关键帮助与操作文字提高字号 |
| 触控与焦点 | 手机课文逐句播放按钮只有 26×29px；分段选择高度 36px；部分公共文字操作触控区偏小 | 逐句播放与分段选择提升到 44px；公共操作至少 44px；为链接与展开菜单补充清晰的键盘焦点样式 |
| 路线状态 | 七步未开放步骤只用小圆点表示，闯关当前关卡与后续关卡视觉接近 | 七步使用锁图标及辅助文字；闯关当前关卡增加边框、编号强调和 `aria-current="step"`，已完成关卡保留勾选 |
| 答题反馈 | 闯关缺少直观的本轮进度；选项只靠颜色表示选择；错误和正确反馈都使用绿色背景 | 增加可读进度条；选中选项增加勾选图形；正确、需要巩固、口语已记录分别使用绿色、暖橙、灰绿反馈，并保留解释文字 |
| 底部答题栏 | 手机闯关操作栏继承外边距，底部仍有缝隙，安全区留白不完整 | 清除固定操作栏外边距，明确底部位置并加入设备安全区内边距 |
| 错误浮层 | 长词汇表发生校验错误后，浮层会截获底部“保存词汇草稿”的点击；提示和导航叠加后阻断继续修改 | 提示文字不截获底层点击，关闭／处理按钮仍可交互；错误存在时为内容末尾增加滚动留白，保存入口可以滚到浮层上方 |
| 样式归属 | 公共语音、内容配置组件的必要样式仍停留在七步模式样式表中，公共设置无法获得这些规则 | 在公共框架中补齐共享组件样式，保持学习模式卸载后的设置布局稳定 |

## 视觉与交互判断

- **品牌与情绪**：保留低刺激配色、温暖背景和学习卡片，不增加打断学习的装饰。儿童端仍突出“接下来做什么”，家长端强化配置与管理信息。
- **信息层级**：页面标题、课程上下文、主要动作、辅助说明各有明确位置。统一设置通过区块和跳转解决长表单的定位问题，保留完整的字段标签与必要说明。
- **文字与颜色**：颜色变化用于加强状态，模式选择仍有文字、闯关选择仍有勾选、反馈仍有标题和解释。正文颜色、选择状态和焦点分别承担不同作用。
- **响应式布局**：在 320、390、1280px 宽度检查公共页面及两种模式。长昵称允许省略并保留完整名称提示；长课程标题和正文可以换行。分段工具栏允许换行，避免扩大触控区后发生横向溢出。
- **空状态与异常**：保留无记录、内容未准备、模式加载失败、音频缺失、保存失败和待确认录音的原有说明与恢复入口；完整回归检查这些入口可继续操作。
- **防误触与操作连续性**：保留家长确认、删除名称确认、退出保存和录音完整回听规则；没有把视觉上的完成状态改成能力掌握。

对七步首页、课文页、答题页的可见文本进行计算样式抽查：原课文译文与背景的对比度约为 2.85:1，调整后约为 5.16:1；新公共辅助文字与卡片背景约为 5.19:1；模式选中文字与选中背景约为 8.40:1。抽查脚本按字号与字重区分普通文本和大文本，跳过禁用控件。结果仅描述这些状态与颜色，不等同于全应用无障碍认证。
