## 1. 媒体卸载与所有权

[公共语音控制器](../src/platform/speech.ts)现在跟踪播放及课程音频生成的所有权。作用域销毁时停止本实例的原生播放或浏览器朗读、取消本实例的生成任务，并移除事件监听。空闲实例或已让出播放权的实例卸载，不会停止其他实例的媒体。

接续播放等待旧设备停止完成再启动。无效资源请求不会夺取播放权；新设备请求失败前，旧播放已先停止，不留下无法停止的旧流。显式 `stop()` 也只停止当前控制器拥有的播放。浏览器取消即使不回调结束事件，待处理的朗读 Promise 仍能结束。

卸载会使加载、播放及音频查询的迟到结果失效；监听注册迟到时立即移除监听。课程音频生成取消只暂停任务，保留已生成的资源，不调用清理课程、删除学习记录或改写快照的接口。

回归用例见[原生生命周期测试](../tests/mode-unload.test.ts)、[浏览器生命周期测试](../tests/browser-mode-unload.test.ts)及[监听注册迟到测试](../tests/speech.test.ts)。覆盖：

- 活动课程播放、试听播放卸载，只停止一次。
- 配置仍在加载时卸载，不启动播放或生成。
- 空闲、已被替代的控制器卸载，不打断当前控制器。
- 原生停止尚未完成时，后续播放等待。
- 无效资源、新请求失败、旧请求迟到成功或失败。
- 音频生成取消、迟到结果与已有音频保留。
- 浏览器没有取消回调时，播放请求仍能结束。

## 2. 七步样式隔离

[Experience.vue](../src/modes/seven-step/Experience.vue)根节点新增 `seven-step-mode` 类。[七步 stylesheet](../src/modes/seven-step/style.css)中的主题、元素、控件、布局、交互状态和媒体查询规则均限定到该根节点，两个动画名称也使用七步专用前缀。

字体、颜色、背景和 CSS 变量从文档根移到模式根；公共层只在[base.css](../src/platform/base.css)保留 `body { margin: 0 }` 的视口重置。不依赖 `@scope`、`:where` 等旧 WebView 不支持的作用域语法。模式样式标签可以继续由构建器缓存，但不再匹配根节点之外的内容。

[真实浏览器隔离测试](../tests/e2e/mode-isolation.spec.ts)在 390px 和 1280px 两种宽度下，先记录中性界面的计算样式，再加载实际七步应用，最后卸载应用、将中性界面移到原宿主。加载期间和卸载后的字体、颜色、边框、间距、尺寸、CSS 变量均与基线一致；七步内部背景和输入框圆角保持原样。测试还遍历实际 CSSOM，包括嵌套媒体查询，检查选择器范围和动画命名。

## 3. 旧课程及学习进度

本轮未更改存储 key、revision 封套、快照版本、v1 迁移、课程或题目 ID、音频资源键、评分及学习事件解释。

[兼容测试](../tests/teaching-modes.test.ts)新增卸载、重载往返：同一份旧自建课程与两个档案的快照连续加载两次，每次卸载后存储字符串逐字不变，重新读取仍与原课程、版本、作答事实和未完成恢复点完全一致。既有固定摘要测试继续比对内置教材、题库、音频清单、自建课程编译结果和学习投影；恢复答案、提示状态及档案隔离测试继续通过。

再次从 Git HEAD 提取重构前实现，与本轮实现做差分：

- 7 组课程、评分、报告及快照运行逻辑一致。
- 5 个页面业务脚本一致；模板仅允许 Experience 根节点新增作用域类。
- 样式声明及规则顺序保持原语义，差异仅为选择器作用域和动画命名。
- 10 类旧快照的新旧结果一致：已发布课程及恢复点、四类草稿、软删除、清理待办、早期 v2、待确认口语、人工复核、真正 v1 迁移、未知版本拒绝、篡改课程拒绝。

差分脚本及结果保存在本地忽略目录：[脚本](../artifacts/validate-seven-step-fixes.mjs)、[结果](../artifacts/seven-step-fixes-equivalence.json)。导入旧/新桥接模块时会出现插件重复注册提示；差分调用的是纯课程及解码逻辑，不执行设备存储。
