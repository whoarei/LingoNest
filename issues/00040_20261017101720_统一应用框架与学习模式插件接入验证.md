# 统一应用框架与学习模式插件接入验证

建立时间：2026-10-17 10:17:20（Asia/Shanghai）。依据：[统一应用框架与学习模式插件界面边界方案](../docs/00022_20261017091925_统一应用框架与学习模式插件界面边界方案.md)。

本轮建立稳定的应用外壳，把七步学习与课文闯关接入为教学工作区。切换模式只更换教学区域，孩子、课程目录、家长空间、设置和系统返回由应用统一管理。正常旧数据读取保持原存储格式，已有课程、作答、未完成会话和音频资源继续使用。

## 1 统一后的界面

| 区域 | 当前行为 |
| --- | --- |
| 孩子空间 | 固定为学习、课程、记录；顶部保持应用品牌、当前孩子和家长空间入口 |
| 家长空间 | 固定为概况、课程、记录、设置；档案管理与模式无关 |
| 课程教材 | 共同目录负责新建、图片、OCR、元数据采用、原文编辑、归档、恢复与彻底删除 |
| 课程详情 | 教材、学习模式、资源三个区域；同一课程分别准备七步与闯关内容 |
| 内容准备 | 家长可以准备非当前全局模式的内容，不会改变孩子的学习模式 |
| 学习记录 | 汇总日期、课程和模式等事实；详细报告由产生记录的模式解释，可跨当前模式只读查看 |
| 课程资源 | 按模式与内容版本选择音频清单，复用公共生成、暂停、继续、删除与配置入口 |
| 学习会话 | 框架提供统一的专注布局、保存退出和返回确认，题面、提示、评分和结算由模式处理 |
| 故障恢复 | 未知模式、插件加载失败或未接入任何插件时，公共管理与设置仍可使用 |

教材阅读独立于学习内容准备，课程尚未生成目标模式时仍可浏览原文。当前课程的学习辅助先通知已连接的模式，再进入公共阅读页；练习内部的原文与提示继续由模式自行控制。

家长确认集中在框架。一轮家长空间操作可以复用已完成的防误触确认，离开家长空间或切换孩子后清除该确认。课程彻底删除、档案删除仍需明确输入目标名称；口语确认仍要求先完整回听录音。

## 2 模块职责

| 位置 | 职责 |
| --- | --- |
| [ApplicationFrame.vue](../src/application/ApplicationFrame.vue) | 公共导航、孩子与家长空间、目录、设置、授权、专注布局和唯一的 Android 返回监听 |
| [workspace.ts](../src/application/workspace.ts) | 教学工作区的学习、内容准备、报告、确认上下文，以及保存、退出、刷新和返回端口 |
| [ModeHost.vue](../src/modes/ModeHost.vue) | 延迟加载已注册的教学组件、提供工作区上下文、隔离插件错误；不再绘制整套应用 |
| [插件契约](../packages/learning-modes/contracts.ts) | 注册教学工作区及只读目录适配器，提供内容状态、事实记录、待办与资源清单；允许空插件目录 |
| [MaterialEditor.vue](../src/application/MaterialEditor.vue)与[material-recognition.ts](../src/application/material-recognition.ts) | 共同教材编辑和识别；保留图片顺序、旋转、明确采用识别结果和多行 JSON 容错 |
| [CourseResources.vue](../src/application/CourseResources.vue) | 根据模式声明的音频清单管理资源，教学模块继续声明音频用途与发布条件 |
| [application/services.ts](../src/application/services.ts) | 组合公共数据、共享写入队列、删除参与者与各模式服务 |
| [legacy-data.ts](../src/application/legacy-data.ts)与[legacy-catalog.ts](../src/application/legacy-catalog.ts) | 应用持有的历史格式兼容适配器；继续使用原存储键和原生接口 |
| [七步工作区](../src/modes/seven-step/Experience.vue) | 七步路线、课文学习、阶段任务、复习、内容准备、评价报告与口语确认 |
| [闯关工作区](../src/modes/passage-path/Experience.vue) | 路径、短练习、辅助、题库审核和闯关报告 |

两个模式均移除了各自的应用顶部栏、一级导航、设置页、家长确认弹层和 Android 返回监听。七步原家长空间缩小为报告与口语确认组件，公共档案和课程管理已上移。

语音配置通过框架提供的共享引用传给各播放器和音频生成器，避免在设置页保存新音色后，仍挂载的学习组件继续使用旧配置。图片预览和滑动删除的基础样式也归入公共组件。

## 3 数据保留与编辑规则

本轮没有整体迁移数据库，没有改动学习记录或课程包的格式版本。浏览器历史键 `lingonest.local.v1`、原生旧快照接口，以及闯关和模式选择的独立文档继续沿用。七步服务与目录的旧导出保留为兼容门面。

旧课程版本、题目与题族标识、评分投影、学习会话和音频清单保持原有含义。正常读取与模式往返切换不会重新编译已发布课程；读取损坏或不支持的数据时停止相关写入，保留原始内容。

共同教材的未发布草稿可以编辑。修改教材会清除该课程尚未发布的七步生成产物并退回原文确认，词汇草稿与其他课程的学习事实保留。闯关候选仍固定其教材快照，发布时校验材料是否过期。任一模式已有发布内容后，共同教材当前版本保持只读。

公共数据当前仍通过历史快照兼容适配器保存，尚未拆成新的物理目录文档。之后若进行独立存储迁移，应另行设计显式迁移和恢复过程。

## 4 保存与上下文保护

- 页面离开前保存正在显示的教学工作区和教材编辑器；失败时保留页面、输入与当前模式。
- 隐藏的教学工作区不会在后续公共页面切换时重复保存旧编辑副本；重新进入准备页时重新绑定最新保存的数据。
- 页面与孩子／家长空间同时提交切换，导航在过渡期间锁定，避免短暂出现错误的管理入口或课程上下文。
- 查看历史报告使用报告课程范围，准备课程不改变孩子实际学习课程；学习操作仍服从全局模式。
- 闯关继续保留精确队列、题面顺序、未提交输入、辅助信息和反馈位置。保存失败后重试与刷新恢复同一会话。
- 内容请求与播放继续使用已有的归属和取消机制；卸载后的生成结果不能覆盖新工作区。
- 已归档、删除和跨模式资源清理继续经过同一删除协调器，保留共享资源的存活引用保护。

## 6 本轮边界

本轮完成应用框架、公共管理入口与两种模式工作区接入。七步与闯关的教学算法、评分规则和已发布内容版本继续沿用。本轮未执行 Android 真机覆盖安装；后续已完成[真机覆盖安装与数据保留验证](00041_20261017102612_统一应用框架重构真机覆盖安装验证.md)。
