# 课程审核阅读式界面设计

建立时间：2026-10-15 12:52:50（Asia/Shanghai）。对应版本：0.1.13 / versionCode 14。

## 页面结构

审核页以内容阅读为默认状态，替代所有字段同时展开的表单。

- 概况卡片展示审核状态、课文段落数、选中词汇数及理解/情境题总数；重点词汇可展开查看词条和释义。
- 内容分为“课文释义”“理解题”“情境应用”，通过带数量的分区按钮切换，一次显示一类。
- 课文释义使用中英对照卡片，保留英文原文，中文释义以浅色区块分隔。英文采用适合连续阅读的衬线字体。
- 理解题默认呈现问题、字母编号选项、正确答案标识及解析，正确项使用浅绿色与勾选标识。
- 情境应用默认呈现任务、参考答案和提示，答案与说明分别排版。
- 每类内容按项提供编辑入口，展开后保留已有字段、长度限制和修改能力；切换分区时收起编辑。字段修改实时进入原有草稿保存流程，“完成编辑”仅收起表单。
- 全部学习任务预览仍默认折叠。底部单独设置审核确认区，启用课程为主按钮，重新生成和返回词汇为次级操作。

移动端和桌面端沿用应用的米白、浅绿与深绿配色。不同内容通过留白、序号和边框组织，避免重复标签和大面积输入框。窄屏保留正确答案的勾选图标及屏幕阅读器文字。

## 审核与数据约束

启用课程仍要求勾选家长审核确认且课程结构有效。修改释义、问题、选项、答案或提示后取消已有勾选，必须重新确认。重新生成替换内容后，默认回到课文释义并收起编辑。

原文和已确认词汇在审核页只读，编辑词汇仍通过返回词汇步骤处理。课程生成、校验、题库预览和发布逻辑沿用既有实现；不更改课程快照格式或旧课程数据。分区和展开状态不持久化，重新进入时从课文释义开始。
