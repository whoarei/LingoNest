# 英语小窝 0.2.3

建立时间：2026-10-25 12:41:12（Asia/Shanghai）。包名 `cn.lingonest.app`，Android 构建号 `21`，最低 Android 7.0（API 24），目标 API 36。

## 本版变化

- 调整应用更新的安装流程：点击“安装更新”后直接打开系统安装器，由手机系统处理安装来源授权与本次安装确认，不再先要求开启长期安装来源许可。
- 更新页补充单次授权提示。若手机显示带“记住我的选择”的安装询问，可保持未勾选，按系统提供的选项允许本次安装；是否支持此方式取决于手机系统。
- 新增独立的“管理安装来源权限”入口，便于手动关闭旧版本已开启的长期许可；从设置返回后不会自动安装。
- 安装器打开失败时保留已校验的安装包，可再次点击安装重试，无需重新下载。

## 安装与更新

已安装 0.2.0 或更高版本的用户可从“更多 → 应用更新”获取本版，也可下载本 Release 的 `lingonest-0.2.3-release.apk` 手动安装。本版沿用现有正式发布证书，Release 同时提供 `update.json`、`SHA256SUMS.txt` 和 `signing-certificate-sha256.txt`。

安装前仍会保存当前学习进度，校验安装包身份、版本、哈希与正式签名，然后交给系统安装器。本版未调整课程和学习数据格式，不预装课程音频或开发者凭据。

## 兼容性与已知限制

- 应用无法通过普通 Android 接口自动撤销安装来源许可。旧版本已经开启的长期许可需在系统设置中手动关闭一次，系统之后如何询问以设备实际行为为准。
- 小米带“记住我的选择”的单次安装弹窗来自用户描述；本版尚未在小米真机验证。其他系统可能仍要求进入安装来源设置，不能保证所有手机都支持单次许可。
- 本版尚未进行真实设备覆盖安装、系统授权弹窗及升级后学习数据保留验收。
