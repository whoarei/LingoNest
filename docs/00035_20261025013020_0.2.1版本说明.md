# 英语小窝 0.2.1

建立时间：2026-10-25 01:30:20（Asia/Shanghai）。包名 `cn.lingonest.app`，Android 构建号 `19`，最低 Android 7.0（API 24），目标 API 36。

## 本版变化

- 修复课程列表、学习记录等短页面的底部导航悬在半屏的问题，统一公共页面与两种学习模式的内容宽度、边距。
- 重新整理家长设置：配置分区采用独立卡片，增加分组跳转，桌面模型配置并排展示，手机纵向排列；恢复主操作、次要操作和返回入口的视觉层级。
- 强化课程模式与语速预设的选中反馈，课程模式支持方向键、Home、End 和键盘焦点恢复。
- 提高课文译文、说话人、题目说明、选项与提示文字的可读性，扩大手机逐句播放、课文分段及公共操作的触控区域。
- 七步路线增加未开放步骤的锁定提示，闯关路线突出当前关卡；闯关答题增加本轮进度条与选中勾选，区分答对、需要巩固和口语已记录的反馈。
- 修复手机闯关答题栏的底部缝隙，补齐安全区留白。
- 修复错误浮层遮挡长词汇表保存入口的问题，校验失败后可以继续修改并保存草稿。

详细设计审查与前后对比见 [UI 设计审查与修复验证](../issues/00057_20261025011827_UI设计全面审查与修复验证.md)。

## 安装与更新

已安装 0.2.0 的用户可从“更多 → 应用更新”获取本版，也可下载本 Release 的 `lingonest-0.2.1-release.apk` 手动安装。本版沿用现有正式发布证书，Release 同时提供 `update.json`、`SHA256SUMS.txt` 和 `signing-certificate-sha256.txt`。

Android 安装仍需在系统安装界面确认。本版没有调整学习数据格式，仍不预装课程音频或开发者凭据。

## 兼容性与已知限制

界面检查覆盖 320、390、1280px 宽度，保持旧 WebView 的布局回退。真实 Android 设备的键盘、安全区、字体渲染、录音权限及覆盖安装后数据保留尚未实测，浏览器和 CI 检查不作为真机验收结论。
