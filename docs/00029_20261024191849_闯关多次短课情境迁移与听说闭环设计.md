# 闯关多次短课、情境迁移与听说闭环设计

建立时间：2026-10-24 19:18:49（Asia/Shanghai）。承接[借鉴多邻国的课程优化设计](00028_20261024173120_借鉴多邻国的闯关课程优化设计.md)，本次将其中的多次短课、情境迁移、听说与结算建议落地。框架接口继续遵循[双教学模式接口契约](00026_20261024162351_框架与双教学模式接口契约.md)，审查与验证见[实施报告](../issues/00052_20261024191849_闯关多次短课听说与结算循环审查验证.md)。本文描述当前实现；较早方案中的单轮通关及版本参数以本文为准。

## 课程层级与推进

共同教材提供课文，闯关包定义交流目标及其引入关卡，每关围绕相同目标安排三次短课。三次都完成后才记录关卡完成，随后开放下一关。每次短课是独立会话，可以退出、重载和继续；不要求一次完成整关。

| 短课 | 学习任务 | 必须保留的覆盖 |
| --- | --- | --- |
| 初识表达 `discover` | 理解课文表达，再借助词块练习、独立补全 | 新目标的理解；承诺回想的目标有无选项作答 |
| 换情境用 `transfer` | 在明确标出的新交流任务中使用相同表达 | 每个新目标有情境应用；需要回想的目标有独立补全 |
| 听说应答 `communicate` | 听懂表达，录下自己的回应并回听 | 每个新目标至少一次听辨和一次口语任务 |

每次基础题仍为 4～6 题，最多两道补练。必要目标覆盖先占预算，之后才穿插到期、薄弱复习。已学目标先有独立机会，再接触同目标答案。换情境和听说不会将已学目标重新当成初学目标。当前固定三种短课是可解释的课程骨架，尚未按个人表现自动增减必修短课数量。

首页逐关展示三次小课及其完成状态，允许重练已经完成的小课。已完成数量从准确孩子、课程、包修订、关卡下的已完成路径会话推导，不额外保存一份可漂移的计数。重练会话不重复增加关卡或短课完成数，进行中的会话优先恢复。

## 情境题库与家长审核

新情境使用题目字段 `context: { kind: "transfer", text }`，界面在题目旁显示“换个情境”。它是教材表达的应用任务，原文依据仍指向原教材，不能把变式当作课文事实。生成提示要求沿用已学表达与熟悉词语，任务说明不直接提供答案；优先改变交流对象、目的或使用条件，而不是只改题干措辞。

编译器检查初识、情境、听说三类候选池能各自组成合法短课，核对每个新目标的理解／回想／听辨／口语覆盖与预算。题目指纹包含情境与口语参考信息，同轮不选重复任务。轮换按本人历史优先使用未练或较久未练变式。同课程的到期、薄弱复习也必须符合当前短课类型；跨课程复习保留来源信息，最多一题，且不抽取其他课程的口语任务。

结构校验不能证明情境有迁移价值，也不能判断自然语言答案的教学质量。因此家长仍须逐题核对整个题库，新增“审核短课”筛选与现有目标、关卡筛选组合使用。情境说明、口语示范及回听要点均可编辑。保存建立新候选修订，撤销被改题目的审核确认；已发布题库、孩子当前会话和历史作答保持各自原版本。预览口语任务只展示示范与要点，不录音、不写孩子记录、不自动通过审核。

## 听辨与口语完成条件

新课程听辨题须完整播放准确来源包的当前题目音频后才能提交。播放结束才保存 `audioPlayed`；停止、失败或页面／课程／孩子／题目变化均不会记作听完。选择输入与已完成播放事实一同保存，普通重载不会要求重新听已完成的片段。

口语题 `speak` 定义交流任务、示范 `sampleAnswer` 和 1～4 项具体的 `criteria`，示范音频文字与参考表达一致。孩子依次执行：

1. 看交流任务和回听要点，可以主动听示范。
2. 使用既有 Android 录音能力说出回应，可以重录。
3. 完整回听本次录音，再选择“我能说清楚”或“还想再练一练”。
4. 提交练习，保留录音、自评及示范参考。

未录音、未完整回听或未自评时不能提交。麦克风拒绝时提供家长开启设备权限入口，恢复后继续原题；保存失败保留录音和自评供重试。退出先结束录音并保存，再释放播放；工作区失效时取消自身录音，异步结果必须核对孩子、课程、会话、题目和工作区激活代次。录音过短、静音和异常中断沿用既有原生质量检查。浏览器不模拟真实麦克风录制，提示在 Android 应用完成口语。

口语 `correct: null` 表示没有自动判分，不计入答对率、错误率或稳定证据。选择“还想再练”只影响结算建议，不能伪造客观答错，也不触发无限补练。播放本题示范按 `sample` 辅助单独记载，只影响当前来源目标；其他原文播放不冒充当前题示范。原文、提示、示范的主动操作与反馈造成的巩固条件分别报告。

## 结算、复访与记录

结算首先显示本轮交流用途，最多列出两个需要再练的目标，并说明接下来是哪一关、哪一次小课。错误或口语自评“再练”时可以直接巩固已完成的小课，也允许继续或休息。重练结果不持续强推立即再练，避免形成推荐循环。口语次数与可客观判分的首答统计分开显示。

首页对已经完成相应小课、目标到期且最近实际作答已间隔至少 24 小时的目标提供“隔天回访”。优先回访情境应用，尚未完成情境小课时回访初识。回访是重练，不重复记通关；完成后根据最新实际作答抑制立即重复推荐。未可信推进的时钟不产生新的稳定证据，时钟回拨时不展示错误的到期建议。推荐与目标进展都按当前孩子、准确课程和发布修订读取。

家长报告显示关卡、短课、首答、辅助、补练及完成录音回听次数；口语历史可逐页回听，旧修订的录音仍作为历史保留。路径完成表示练过，至少三个相隔 24 小时的合格独立成功轮次才计为稳定表现，口语自评不降低这个门槛。

## 数据与资源归属

| 数据／能力 | 所属位置与约束 |
| --- | --- |
| 课程结构与短课规则 | 闯关核心 `curriculum/authoring/scheduler/runtime`，不向框架增加教学阶段枚举 |
| 冻结会话及作答 | 闯关独立快照；按孩子、主课程、包修订、会话与题目索引校验 |
| 设备录音与回听 | 公共原生能力端口；教学完成条件和录音解释由闯关拥有 |
| 录音资源清单 | 主会话 `recordingPaths`，包含替换过的录音，每条路径必须属于该孩子 |
| 归档、恢复、彻底删除 | 共同目录与既有删除协调器；闯关提供自身资源和删除参与者 |
| 公共记录 | 模式输出通用记录文字，不让框架解释口语自评或短课推进 |

替换录音不会使旧文件脱离资源清单。归档课程保留会话、录音及完成记录，恢复后可继续。彻底删除主课程清理其全部会话录音；删除孩子只清理本人的录音和进度。删除协调器先登记清理意图，资源失败可重启续作，仍被其他数据引用的资源保留。跨课程复习不携带其他课程口语，避免主会话与录音所属课程混淆。七步数据和其他孩子、其他课程的状态不受此模式写入影响。

新生成包使用规则版本 `3`、提示／编译版本 `2`，新会话记录调度版本 `5`。既有已审核发布包按自己的规则和冻结题序解释，不把历史完成伪造为三次小课；需要新课程结构时重新生成、审核并发布。本次未读取或恢复旧七步合并快照，也没有新增跨模式教学兼容层。

核心测试与浏览器夹具覆盖规则、恢复、失败、隔离、删除和交互。它们不能替代真实设备麦克风、真实模型题库质量与儿童学习效果验证；这些边界在界面和报告中明确，不能将录音完成描述为发音已正确。
