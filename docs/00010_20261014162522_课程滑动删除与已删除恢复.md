# 课程滑动删除与已删除恢复

建立时间：2026-10-14 16:25:22（Asia/Shanghai）。对应版本：0.1.7。

0.1.8 已新增已删除课程的彻底删除，并在没有已删除项时隐藏入口，见[彻底删除与入口隐藏规则](00011_20261014170029_已删除课程彻底删除与入口隐藏.md)。以下内容保留 0.1.7 实施记录，可恢复删除及滑动交互继续有效。

## 当前行为

课程删除改为可恢复的移除，不再弹出确认页、要求勾选确认或进行成人算术确认。详情页点击“删除课程”直接移入“已删除”。课程列表支持自建课程左滑：短滑露出删除按钮，点击即删除；长滑达到阈值后松手直接删除。删除成功显示“撤销删除”，也可随时进入“已删除”列表恢复。

纵向滑动保留滚动行为，不触发删除；轻微位移不当作删除手势。滑动后阻止附带的点击事件进入详情，取消手势或指针离开后仍可继续操作。列表同时只展开一个删除按钮，键盘聚焦删除按钮时自动展开。内置样例不提供删除操作。

“已删除”按最近删除优先展示课程标题、原编辑/启用状态与删除时间，提供一键恢复。恢复后回到原课程列表，原文、图片、词汇、教学内容、音频、孩子作答、录音、确认记录与练习恢复点都保留。草稿回到原编辑步骤，已启用课程保持原题库及版本。

删除正在使用的课程时，各孩子的当前课程选择回到内置课程；课程记录仍留在本机。恢复课程不会自动改变孩子当前学习课程，家长可重新指定，原进度随原课程 ID 继续使用。

## 保存与兼容

`CourseRecord` 新增可选 `deletedAt`。本机课程库保留全部记录，正常列表过滤已删除项，已删除列表读取带时间戳的项。题库校验包含已删除课程，以保留历史事件与恢复点的引用合法性；当前学习课程引用必须指向未删除、已启用的课程。

删除与恢复均通过已有原子快照提交。删除详情中的草稿先保存最近编辑；保存失败时停留当前页，不移入已删除。已删除项不能通过延迟自动保存重新写成正常课程，只能从恢复接口移除删除标记。新版删除不发起原生资源清理，也不建立新的清理待办。

正常自建课程最多 30 门，含已删除的总保存上限为 300 门；快照仍受 10 MiB 上限保护。正常列表已满时恢复会提示先移走一门课程，不会丢弃已删除内容。

继续使用 `formatVersion=2`，兼容 0.1.5/0.1.6 没有 `deletedAt` 的课程。0.1.6 已完成的永久删除没有保留学习记录，无法被本轮恢复；旧版本未完成的原生清理待办仍按旧规则处理。当前“已删除”没有自动到期清理或永久清空功能。

本说明替代[0.1.6 删除确认与永久清理规则](00009_20261014160747_课程删除详情页面与设置返回规则.md)中的删除部分；详情页面及设置返回规则继续沿用。
