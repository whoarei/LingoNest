# 英语小窝 0.2.2

建立时间：2026-10-25 10:22:25（Asia/Shanghai）。包名 `cn.lingonest.app`，Android 构建号 `20`，最低 Android 7.0（API 24），目标 API 36。

## 本版变化

- 文字识别与课程生成配置新增“保存并测试”，使用与实际教材处理相同的请求流程验证当前模型；识别测试会发送内置示例图片，生成测试会检查结构化文本返回。
- 区分 API Key 无效、访问权限不足、接口或模型不存在、额度或请求受限、网络超时及返回格式不兼容等失败原因，方便在设置页排查配置。
- 三处 API Key 输入框新增小眼睛，可切换显示或隐藏当前输入的密钥；保存后清空输入并恢复隐藏，已有密钥继续加密保存在本机。
- 重新整理模型配置界面：识别与生成采用独立卡片，显示待保存、待测试、测试通过或失败状态；测试反馈保留在对应卡片内，修改字段后需重新测试。
- 语音配置分为服务连接、音色与播放两组，精简按钮与提示文字，将详细说明收进折叠区；适配手机单列与桌面双列布局。
- 测试期间防止重复操作，离开设置页会取消正在进行的模型测试。

## 安装与更新

已安装 0.2.0 或更高版本的用户可从“更多 → 应用更新”获取本版，也可下载本 Release 的 `lingonest-0.2.2-release.apk` 手动安装。本版沿用现有正式发布证书，Release 同时提供 `update.json`、`SHA256SUMS.txt` 和 `signing-certificate-sha256.txt`。

Android 安装仍需在系统安装界面确认。本版未调整课程和学习数据格式，不预装课程音频或开发者凭据。

## 兼容性与已知限制

- 模型设置及测试功能在 Android 应用中使用。每次测试会向用户配置的服务发送内置示例，可能消耗少量额度。
- 测试通过表示内置示例可用，实际教材仍可能受模型能力、长度、内容及服务配额限制；更换配置后应重新测试。
- 小眼睛用于核对当前输入的密钥，已保存的密钥不从原生存储回传显示；留空可沿用已保存的密钥。
- 界面已检查 320、640、1280px 宽度；本版尚未进行真实设备覆盖安装及安装后学习数据保留验收。
