## 1. 本轮可以运行什么

| 功能 | 当前实现 |
|---|---|
| 课程内容 | 保留内置 Unit 1 Lesson 1 三图对话（15 个话轮、25 个句子），新增自建课程草稿、原文与词汇确认、教学内容审核启用及多课程切换 |
| 七阶段训练 | 读懂故事、词汇、句型、朗读、背诵、默写、迁移的学习路线；共 71 道内置练习，顺序解锁 |
| 文字作答 | 选择、单词拼写、句子输入、词块排序；本地确定性评分、提示、参考答案和下一题 |
| 口语练习 | Android 麦克风录音、回放、质量门禁；有效录音提交后为待人工确认，不显示自动发音分 |
| 人工确认 | 写入操作前成人防误触确认，先回听再确认通过或仍需练习；人工复核事件替换有效评价，避免重复计入 |
| 复习与成长 | 基于真实作答事件重建能力状态，区分训练完成、待人工确认与掌握；按到期时间和延迟资格组织复习 |

## 2. 学习规则如何落地

### 2.1 阶段完成与掌握分别计算

当前阶段完成条件是：当前轮次中，每个 required 目标格都有 H0、`firstTest=true` 的通过结果。提示后答对保留为练习，不替代独立检查。这个首版规则比设计中部分阶段的 80% 通过比例更严格，尚未实现完整 `StageSpec.completion` 配置驱动的解释器。

口语目标允许有效录音处于 `needs_review` 时计入任务完成并进入后续阶段，但阶段“已验证”仍要求人工通过；口语待确认不会增加正式成功证据，也不会被当成自动失败。路线的 `done/total` 统计目标格，练习页的题号统计当前轮次题目，两者可能不同。

“本轮完成”只表示当前题序已经走完。一次高分或七阶段完成均不直接把能力标记为已掌握。

### 2.2 评分和掌握证据

规则实现在独立模块 [packages/learning-engine/src/index.ts](../packages/learning-engine/src/index.ts)，输入/事件类型见 [model.ts](../packages/learning-engine/src/model.ts)。

- 选择和排序按完整 ID 集合或序列判定；重复、遗漏、额外项不通过。
- 拼写显示字符相似分，但通过要求规范化后的完整正确答案。
- 句子输入按词和字符对齐给出分数，并保护否定表达及题目关键词；每个批准答案独立计算，不拼接多个答案的最高分。当前句子评分未实现设计中全部可配置正字法分项和有限语法注册表。
- 口语只产生待评记录；家长确认给出通过/未通过。录音能量检查仅用于排除明显无效输入，不能证明语音清晰度或发音正确。
- 正式证据采用通过/未通过的二元结果，初始 `alpha=1、beta=1`。无提示文字输出和人工确认的基础权重为 1，选择/排序为 0.5；同格同题族每天最多计一次，每格每日有效权重上限为 2。
- 掌握要求估计至少 0.80、至少 3 条有效证据、有效权重至少 3、满足独立性和跨日门槛、发生合格延迟复测通过、最近合格结果通过且时钟可信。固定原文朗读/回忆/默写要求至少 3 个可信学习日和 3 个会话；其他目标至少 2 个学习日和 2 个题族。口语还需要人工确认。
- 最新合格失败优先显示需复习，即使当天证据权重已经封顶；失败清除旧延迟通过资格。人工复核按原作答时序重建，不把复核当天作为新的独立练习。

本应用不把 Beta 估计解释为经过校准的真实记忆概率，也未验证对儿童学习效果的提升幅度。

### 2.3 暴露、延迟和复习

查看课文、提示、参考答案以及相关音频会记录对应目标的暴露。涉及答案的展示先保存暴露事实；保存失败时不继续揭示或播放。S4 的原文是朗读基准刺激，额外示范播放会降低本次独立性；S5 查看原文记为辅助练习；S6 听写题目的音频是题型的基准刺激。

暴露和合格首次检查推进延迟锚点。正式复测需要同时到达 `dueAt` 与锚点后至少 24 小时的 `eligibleAt`；跨午夜两分钟不能充当隔日复测。提前练习不推迟原 dueAt。复习间隔为 1、3、7、14、30 天，每天每格最多晋级一次，失败回到首层并安排下一日。

界面复习入口只包含已测、到期并满足延迟资格的目标，不把未学目标混入复习而越过阶段顺序。时间异常可以保留作答，但不能据此完成跨日或延迟掌握证明。

## 3. 存储、录音和隐私边界

### 3.1 当前是原子快照存储

[src/storage.ts](../src/storage.ts) 的 `LocalState.formatVersion=2` 是当前运行状态信封，包含档案、课程库、课程选择、事件、练习恢复点和待清理任务；支持从旧版 formatVersion=1 内置课程快照迁移。它**不是**设计文档的 `LessonPackage.schemaVersion=2.0.0`，也不是正式课程包导入格式。

Android [NativeStateStore.java](../android/app/src/main/java/cn/lingonest/app/NativeStateStore.java) 使用 `app_state` 单表保存整个 JSON 状态的 UTF-8 BLOB、revision 和 SHA-256。写入在 SQLite 事务中检查 expectedRevision 并递增版本；旧快照哈希或结构损坏时拒绝覆盖并保留原数据。读取采用有界分块，避免把较大 BLOB 一次装入 CursorWindow。

当前快照总容量上限为 **10 MiB**。事件和快照存于同一原子负载中，学习状态由事件重建；尚未落地设计文档中的完整 16 表、独立事实索引、正式 purge epoch、课程迁移及导出恢复。不能将此存储实现描述为已经实现全套关系模型。

### 3.2 本机保护与删除

- 数据库和录音位于 Android 应用私有目录；当前 SQLite **未加密**，未接入 SQLCipher，不能宣称具有数据库静态加密。
- Android 自动备份已禁用，并配置了排除规则。明确配置 AI 后发送朗读文字；0.1.5 仅在主动识别或生成时发送所选图片或课文，学习档案和孩子录音不上传。供应商 Key 使用 AndroidKeyStore 的密钥加密保存，不放入学习数据库或 APK。
- 只有用户点击录音后请求麦克风权限。原生层限制录音时间，并拒绝过短、明显静音、达到上限而可能截断以及被后台/音频打断的录音；这些检查不替代人工回听。
- 删除档案先保存删除后的状态与 `pendingDeletions`，再清理该档案的录音；失败时保留最小待办，下次启动继续清理，界面不能把清理失败当作全部完成。
- 当前没有设计中默认 7 天录音 TTL 清理器；录音保留策略仍需后续实施。已提交录音随档案删除清理，失败/中断的临时录音由原生流程处理。
- 家长入口的算术题用于防止误触，不是身份认证、账号安全或磁盘加密措施。共享设备仍依赖设备锁屏和监护人的实际管理。

原生接口见 [LingoNativePlugin.java](../android/app/src/main/java/cn/lingonest/app/LingoNativePlugin.java)、[NativeGuards.java](../android/app/src/main/java/cn/lingonest/app/NativeGuards.java) 和 [RecordingQuality.java](../android/app/src/main/java/cn/lingonest/app/RecordingQuality.java)。接口限制录音路径和数据范围，不开放任意 SQL 或任意文件访问。

浏览器预览地址为 `http://127.0.0.1:5173`。浏览器可以验证档案、课程核对、文字训练、反馈、复习及成长页面；**浏览器不提供录音**。浏览器状态也不与已安装 Android 应用同步。

APK 不附带课文音频。家长配置自己的服务、Key 与音色，试听后明确生成整课；学习优先读取已生成的长期课程资源，语速直接调整播放，不重新生成。未生成时设备模式可以使用系统英语离线 TTS，AI 模式会提示准备音频，学习时不自动请求转换。详见 [无音频安装包设计](00006_20261013210250_用户配置生成课程音频与无音频安装包.md)。系统和 AI 音色都不是已经通过教材审核的配套示范录音，仍需实际回听。浏览器预览不加载 Android 私有课程音频。

### 4.2 Android 构建和安装

```powershell
npm run android:debug
```

[构建脚本](../scripts/build-android.ps1) 会执行 Web 构建、Capacitor 同步、Gradle assembleDebug，并复制 APK 与 SHA-256 文件。SDK 优先使用 `ANDROID_HOME`，未设置时默认使用 `E:/Android/sdk`。

调试包路径：`artifacts/lingonest-0.1.8-debug.apk`；校验文件为同名 `.apk.sha256`。调试包用于设备试用，不是正式发布签名产物。安装示例：

```powershell
E:/Android/sdk/platform-tools/adb.exe install -r artifacts/lingonest-0.1.8-debug.apk
```

需要签名构建时，在当前构建环境提供以下变量，再运行 `npm run android:release`：

| 环境变量名 | 用途 |
|---|---|
| `LINGONEST_KEYSTORE_PATH` | 签名库路径；脚本未指定时默认 `E:/Android/libb.keystore` |
| `LINGONEST_KEYSTORE_PASSWORD` | 签名库密码，必须由本地构建环境注入 |
| `LINGONEST_KEY_ALIAS` | 使用的密钥别名 |
| `LINGONEST_KEY_PASSWORD` | 密钥密码，必须由本地构建环境注入 |

脚本检查变量是否存在，不输出密码值。不要把密码写入仓库、文档、脚本或版本控制下的配置文件。签名产物路径为 `artifacts/lingonest-0.1.8-release.apk`；未提供有效签名材料时不会把未签名文件当作 release 交付。

## 6. 明确未完成的设计范围

以下能力仍属于后续实施，不应从 UI、版本号或调试包推断已完成：

- 图片裁切编辑器、正式内容审核流水线及课程修订版本管理；原文校对、模型识别/生成接口与家长审核已在 0.1.5 实现，真实模型联调待验证。
- 云 ASR、音素或发音评分、FastAPI 网关、PostgreSQL、对象存储和云作业；当前模型请求由设备直接发起。
- 正式 schema 2.0.0 课程包的运行时 Schema、完整导入/导出、签名发布、不可变包安装及多课程迁移。
- 设计中的完整 16 表存储、课程级删除与 purge epoch、完整事件契约迁移、检查点及 SQLCipher 集成。
- 已审核的教材示范音频、正式资源授权闭环、自动 7 天录音清理及加密备份/导出。
- 全部按策略配置的阶段完成解释器、开放表达评价、全部评分模式和正式全能力覆盖课程包。

当前内置课程和运行状态都使用专用精简类型。即使名称与设计契约相近，也不能直接把 `LocalState`、内置 `Exercise` 或调试 APK 当作正式 Lesson Package 交付。
