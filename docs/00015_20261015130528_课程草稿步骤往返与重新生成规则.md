# 课程草稿步骤往返与重新生成规则

建立时间：2026-10-15 13:05:28（Asia/Shanghai）。对应版本：0.1.14 / versionCode 15。

## 导航

未启用课程的步骤栏支持点击导航。原文校对、重点词汇、生成课程、审核课程中，当前及已经到达的步骤可以往返；尚未完成前置确认的后续步骤禁用。音频准备仍以审核启用为前提，已启用课程继续保持原版本，不通过步骤导航退回编辑。

当前浏览步骤与草稿实际到达的阶段分开处理。往返查看会先保存草稿，保留原文、词汇、已生成释义和题目；保存失败时留在原页面。已审核内容回到原文或词汇页面时，展示修改会影响生成内容的说明。

步骤切换不调用模型，不触发重新生成。关闭后重新打开课程，按已保存的实际阶段恢复；临时浏览位置不另行持久化。

## 重新生成

审核页提供“返回生成课程”。已有学习草稿的生成页提供“重新生成本课学习内容”和“返回审核课程”。仅新结果通过校验且保存成功后，替换原学习草稿并进入审核；网络失败、结果异常、保存失败或主动停止都保留原学习草稿。

识别、生成请求以及音频生成进行中，步骤导航禁用；停止后可继续切换，迟到的结果不能覆盖当前状态。启用课程仍需家长审核确认。

## 修改与失效

| 实际修改 | 处理 |
|---|---|
| 标题、教材或单元、原文 | 回到原文校对阶段，取消原文及审核确认，清除旧生成结果，保留图片和词汇，需要重新确认后生成 |
| 选中词汇的词条、释义、例句或选择集合 | 回到词汇阶段，清除旧生成结果，需要重新确认词汇并生成 |
| 未选中词汇的内容 | 不影响已生成内容 |
| 审核中的释义、题目、答案或提示 | 保持审核阶段，沿用审核页编辑与重新勾选确认规则 |
| 仅查看步骤 | 保留生成结果 |

修改以实际字段内容变化为依据。切换课程、保存快照或生成成功时替换本地记录，不视为上游修改。原文和词汇确认仍需通过原有校验，不能借步骤栏跳过。

本规则替代[早期课程创建说明](00008_20261014152914_课程新建词汇确认与多课程管理.md)中“返回原文或词汇即清除下游内容”的行为。持久化阶段与课程结构约束继续沿用既有格式，无快照迁移。
