## 1. 使用入口与范围

进入“设置与家长入口”，完成防误触题，在“家长空间 → 课文朗读”选择朗读方式。AI 设置支持服务地址、协议、语音模型、API Key、音色和可选风格指令；保存后可立即试听，课文和练习示范使用同一配置。

配置按设备保存，多学习档案共用一套服务和声音。默认使用设备离线朗读，用户明确切换 AI 后才向配置的服务发出请求。浏览器只支持设备朗读预览；API 配置和 AI 音频下载使用 Android 原生桥。

用户提供的服务是 `https://api.xiaomimimo.com/v1`。本地 `.env` 的 `MODEL` 留空，经实际模型列表与语音请求验证后选择 `mimo-v2.5-tts`，默认英语音色 Chloe，默认播放速度 0.9×。Key 不放入课程、学习数据库、前端持久化或 APK。

## 2. 协议与音色

“OpenAI 兼容”需区分聊天协议和语音协议，普通聊天模型不能自动作为语音模型。Base URL 填写服务根路径（例如带 `/v1`），应用追加对应路径。

| 接口类型 | 请求与响应 | 可选音色 |
|---|---|---|
| OpenAI 兼容语音接口 | POST `/audio/speech`；model、input、voice，MP3 二进制输出；模型支持时发送 instructions | 提供 OpenAI 音色名称列表，也可填写自定义名称；第三方及不同模型以其实际支持范围为准 |
| 小米 MiMo 语音接口 | POST `/chat/completions`；目标原文放 assistant 消息，可选朗读风格放 user 消息；audio 指定 wav 和 voice；解码 choices[0].message.audio.data | Chloe、Mia（英语女声），Milo、Dean（英语男声）；支持填写服务商自定义音色名称 |

协议依据：[OpenAI TTS 指南](https://developers.openai.com/api/docs/guides/text-to-speech)、[OpenAI Speech API](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)、[MiMo v2.5 语音合成指南](https://mimo.mi.com/docs/en-US/quick-start/usage-guide/audio/speech-synthesis-v2.5)。

界面明确标注“AI 合成语音”，并说明首次生成会发送朗读文字。直接发送已核对的课文原文，不经过通用聊天模型改写；供应商是否逐字读对仍需家长实际回听。未实现克隆音色、设计音色或音频质量自动评分。

## 3. 语速和缓存

界面滑块为 0.5–1.5×，每步 0.05，快捷选项为 0.75、0.9、1.0、1.25。AI 请求按正常速度合成，Android MediaPlayer 在播放时调整速度并保持 pitch=1；变速复用已有缓存。设备模式通过系统 TTS 的 speechRate 设置语速。

缓存键为“协议、完整合成端点、实际请求正文”的 SHA-256，正文包含文字、模型、音色和风格；不包含 Key 与播放速度。改变音色、模型、服务或风格会生成新音频；改变语速不会重复收费请求。修改 Key 保留同一内容缓存的离线可用性。

音频存于应用私有 `speech-audio/` 目录，文件名仅为哈希。下载后先写临时文件、同步并验证可播放时长，再原子改名；失败或取消的输出不会成为有效缓存。单段音频最多 16 MiB，总缓存最多 128 MiB，按最近使用时间清理旧项。家长可单独清理缓存，学习记录与录音不受影响。

缓存存在时可离线播放；未缓存的内容首次需要联网。不会自动改用设备音色或自动重试收费请求。家长可以明确切回设备朗读。生成和播放均有状态及停止入口，进入后台、录音、音频焦点丢失和耳机断开会取消当前音频操作。

## 4. 密钥与请求保护

`SpeechConfigStore` 使用 AndroidKeyStore 的 AES 密钥与 AES-GCM 加密整个配置，存入私有 SharedPreferences。JS 读取只得到公开配置和 hasKey，不能读回 Key；输入框只暂存本次输入，保存成功或退出设置后清空。留空保存时保留当前 Key；切换服务 origin（协议、主机、端口）必须重新填写，防止旧 Key 被自动发送到另一服务。

请求只允许 HTTPS，不允许 URL 中的账户、查询参数或片段，不跟随 HTTP 重定向。连接超时 15 秒、读取超时 90 秒；错误反馈使用固定脱敏文案。Capacitor 桥日志继续关闭，Android 备份继续禁用。学习数据库仍未加密，本次密钥加密不改变其边界。

此功能新增 INTERNET 权限。学习快照、麦克风录音仍仅在本机；AI 请求仅包含朗读文字、模型、音色和风格，不上传档案昵称、学习记录或孩子的录音。

## 5. 本地调试与导入

`.env` 仅用于开发机验证和向已安装的调试应用导入配置，Git 忽略该文件；可复制根目录的 [.env.example](../.env.example) 填写。常用变量为 BASE_URL、MODEL、API_KEY 和可选 TTS_VOICE。没有使用 VITE_* 注入密钥，不会随打包自动配置用户手机。

在仓库根目录运行：

~~~powershell
# 调用服务生成一段短音频，仅输出非敏感元信息
node scripts/check-speech-api.mjs

# 安装新版时保留应用数据
E:/Android/sdk/platform-tools/adb.exe install -r artifacts/lingonest-0.1.2-debug.apk

# 连接唯一在线设备后，将本地 .env 配置直接送入原生加密存储
# 多设备时先设置 $env:ANDROID_SERIAL
node scripts/configure-speech-android.mjs

# 可选：实际播放示例、重复缓存播放和 0.75× 变速缓存播放
node scripts/configure-speech-android.mjs --verify
~~~

导入工具要求调试 APK 的 WebView 调试桥可用，日志不输出 Key 或 CDP 请求表达式。它不修改学习快照或建删档案；成功后重新打开应用，让界面重新加载公开配置。正式用户使用应用内设置入口。
