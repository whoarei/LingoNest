# 统一应用框架与学习模式插件界面边界方案

本篇保留首次方案／审查时的历史状态；公共数据已按[独立存储设计](00025_20261024151055_公共目录与教学数据独立存储设计.md)完成物理拆分并放弃旧数据兼容。已移除适配器的源码链接现指向对应的接替入口。

建立时间：2026-10-17 09:19:25（Asia/Shanghai）。状态：统一框架与两种模式工作区的首轮重构已实施，见[实施与验证记录](../issues/00040_20261017101720_统一应用框架与学习模式插件接入验证.md)。下文保留目标职责边界和重构前的问题背景；当前实现与开发入口见[当前实现与开发验证指南](00023_20261024101255_当前实现与开发验证指南.md)。公共数据的独立物理存储迁移仍需另行实施。

LingoNest 保持一套稳定的应用框架。接入七步学习插件，框架就提供七步学习；接入课文闯关插件，框架就提供闯关学习。孩子、课程教材、家长空间、设置和系统导航属于应用；生成什么学习内容、如何学习、如何复习和怎样评价属于插件。

判断归属时，先问两个问题：**拿掉全部学习模式后，这项功能是否仍有必要？这项功能是否决定孩子怎么学、怎样才算学会？** 前者通常属于框架，后者属于学习模式。有共同界面的功能还要拆开“谁提供服务”和“谁作教学决定”。

沿用现有产品约束：家长选择一个本机全局学习模式，作用于所有孩子和课程；每门课程可以保留两种模式的内容与记录。本文重点修订界面和模块职责，不引入课程级模式开关。

## 1 重构前的界面边界问题

以下记录的是 2026-10-17 重构前确认的结构问题，不表示这些界面问题仍存在于当前代码。对学习节奏、题目质量和孩子使用感受的评价仍需要单独验证。

| 重构前状态 | 相关代码位置 | 当时对界面重构的含义 |
| --- | --- | --- |
| `App.vue` 只渲染 `ModeHost`，宿主根据模式加载一个完整的 `Experience` | [App.vue](../src/App.vue)、[ModeHost.vue](../src/modes/ModeHost.vue)、[插件注册契约](../packages/learning-modes/contracts.ts) | 当前切换的是整套应用体验，宿主尚未拥有稳定的应用外壳 |
| 七步实现自己的顶部栏、小窝／课文／复习／成长导航、家长空间、设置与 Android 返回 | [七步 Experience](../src/modes/seven-step/Experience.vue)、[七步 ParentSpace](../src/modes/seven-step/components/ParentSpace.vue) | 应用入口与七步教学功能混在一起 |

| 公共目录契约已存在，实际目录和删除协调器仍由七步兼容服务提供 | [目录契约](../packages/learning-modes/catalog.ts)、[应用服务组合](../src/application/services.ts)、[兼容目录](../src/application/catalog.ts) | 继续使用现有兼容存储时也应先把公共服务的所有权交给应用，避免框架依赖七步插件才能运行 |

因此，本轮首先固定应用层的信息结构和页面归属，再调整闯关的路径与练习体验。仅给闯关换皮，仍会留下两套软件入口。

## 2 产品对象与插件的关系

```text
LingoNest 应用框架
├─ 孩子档案、当前孩子
├─ 课程目录、当前课程、教材与图片
├─ 家长空间、设置、资源与保存
└─ 学习模式插件目录
   ├─ 七步学习：内容准备、七步学习、复习、七步评价
   └─ 课文闯关：题库准备、路径与短练习、补练、闯关评价

同一门课程 courseId
├─ 共同教材 sourceRevision
├─ 七步学习内容版本 + 每个孩子的七步状态与记录
└─ 课文闯关内容版本 + 每个孩子的闯关状态与记录
```

这里的插件是随应用注册和发布的教学模块，包含逻辑、页面和数据适配器。首轮不建设插件商店，也不从课程包执行脚本。

需要区分三个独立状态：插件是否可用、家长当前选用了哪个插件、某门课程在该插件下是否已有可学习内容。接入插件提供的是教学能力；新课程仍需准备内容、审核和满足资源要求。

切换模式保留孩子、课程和各模式的进度。若当前课程缺少目标模式内容，保留课程选择并显示准备提示；孩子可以从课程列表主动选择另一门可学课程。系统不会默默切课或回退到其他模式。

## 3 固定应用导航

### 3.1 孩子空间

```text
顶部：LingoNest／英语小窝    当前孩子    家长空间

学习                     课程                    记录
├─ 当前课程与模式名称     ├─ 统一课程列表          ├─ 按日期查看学习足迹
├─ 模式学习主页插槽       ├─ 教材详情与原文        ├─ 按课程、模式查看记录
└─ 模式内部入口           └─ 当前模式可学状态      └─ 模式报告插槽
   七步：阶段、复习
   闯关：路径、巩固
```

三个一级入口的位置、样式和语义固定。七步的“复习”和闯关的“巩固”放在各自学习区域，由模式决定是否出现、出现在哪以及如何安排。框架不把复习做成所有模式必须具备的统一调度器。

“学习”页的框架部分只提供当前孩子、当前课程、模式标识和加载／准备／错误状态。推荐什么任务、主按钮写什么、学习路线长什么样，都由插件提供。孩子端显示模式名称，模式切换放在家长设置中。

“课程”页管理的是共同课程目录。孩子可以浏览和选择课程；新建、编辑、删除和恢复等管理操作在家长空间完成。

“记录”以日期、课程和模式标识组织事实。详细评价由产生记录的模式解释；当前选用闯关时，仍可只读查看七步历史报告。插件暂不可加载时显示基础信息和不可用状态，保留原记录。

### 3.2 家长空间

```text
顶部：家长空间    当前孩子／管理孩子    返回学习空间

概况                    课程                    记录                 设置
├─ 准备与审核待办       ├─ 共同课程目录          ├─ 学习事实           ├─ 当前学习模式
├─ 模式提交的待确认项   ├─ 新建教材              ├─ 模式评价报告       ├─ 孩子档案
└─ 学习事实概况         └─ 课程详情              └─ 录音等待确认项     ├─ 文字识别／内容模型
                           ├─ 教材                                   ├─ 语音与音频
                           ├─ 学习模式                               └─ 本地数据与应用信息
                           └─ 资源
```

家长确认由框架统一执行。插件可以提出“发布内容”“确认口语”等受保护操作，但不能再实现自己的家长身份流程。现有防误触确认的强度不因本次界面梳理而改变。

“概况”的通用统计只展示具有相同定义的事实，例如发生学习的日期和已提交作答次数。复习目标数、掌握率、路径进度和稳定表现均来自对应模式；不能相加成一个跨模式掌握率。

### 3.3 练习中的专注界面

开始学习后，由框架进入专注布局，暂时收起一级导航和课程／孩子切换入口。框架保留统一的退出位置和保存状态；插件绘制题面、学习进度、音频入口、提示、反馈及继续操作。

```text
保存并退出                          当前课程
──────────────────────────────────────────
         模式学习会话插槽
  七步：某个阶段的任务、朗读或回忆
  闯关：本关任务、即时反馈与必要补练
──────────────────────────────────────────
       插件提供的作答与继续操作
```

退出前框架调用插件的离开处理并保存状态；保存失败时留在当前界面。题目序号、补练是否计入分母、结束条件和结算内容属于模式，框架不推算统一题量。

## 5 最容易再次混淆的边界

### 5.1 新建课程与生成学习内容

新建课程先建立共同教材：标题、原文、图片和教材修订。此时不要求选择必学词，也不自动生成七阶段结构。

教材保存后，在课程详情的“学习模式”中，为七步或闯关准备内容。家长可以先准备尚未全局启用的模式，其编辑上下文明确绑定课程、模式和教材修订；准备内容不会改变孩子的当前模式。

两种模式的内容准备过程可以不同。七步可以继续确认词汇、生成与审核；闯关可以分析表达块、生成题库、审核关卡与题目。框架统一保存和发布入口，不强制相同数量的步骤或相同审核字段。

### 5.2 原文阅读与学习辅助

课程页的教材阅读是独立浏览行为。练习中的“查看原文”必须由模式决定并记录：回忆阶段与开放阅读任务的教学意义不同。框架不能在专注界面放一个始终能绕过模式规则的全局原文入口。

从练习退出后再浏览教材，应保留可追溯的阅读／辅助事实，供模式判断恢复会话时是否还能作为独立证据；框架不自行判断“这次阅读是否影响掌握”。

教材页读取当前教材；练习、审核和历史报告读取它们绑定的教材快照。教材更新不改变已发布题目与历史作答的原文依据。

### 5.3 通用音频服务与教学规则

框架管理语音配置、实际文件、播放失败和音频生成任务。插件声明所需文本、用途、所属版本及必需性，并决定某次播放是正常题干还是额外帮助。

“音频是否齐全”由框架根据模式资源清单检查；“这道题缺少音频还能不能做”“播放后是否算完成”由模式定义。实际播放失败不能被框架或插件当成成功。

### 5.4 学习记录与能力报告

框架保存可靠的事实外壳：孩子、课程、模式、内容版本、事件标识和发生时间；作答等载荷由模式校验。模式给出本次表现、长期能力状态及建议，并提供报告组件。

七步“完成三步”和闯关“完成三关”只能分别展示。“练过”“完成路径”“表现稳定”保留各自含义。无法由现有事件可靠还原的学习时长不补算成事实。

## 6 关键界面方案

### 6.1 同一学习页切换教学内容

```text
英语小窝                            小雨  家长空间
一起加入运动队                  当前模式：七步学习

[插件区域]
继续：搭好句子
读懂故事 ✓ → 认识单词 ✓ → 搭好句子 → …
复习入口与能力提示

学习                    课程                    记录
```

切换到闯关后，顶部、课程上下文和底部入口保持一致。只替换插件区域：

```text
英语小窝                            小雨  家长空间
一起加入运动队                  当前模式：课文闯关

[插件区域]
继续：聊聊喜欢的运动
已完成关卡 → 当前可进入关卡 → 后续关卡
本轮学习／巩固入口与路径反馈

学习                    课程                    记录
```

以上名称和进度用于界面示意。七步保留实际七个阶段：读懂故事、认识单词、搭好句子、开口朗读、试着回忆、听写句子、换个情境。闯关名称和数量来自该课程的已发布题库，不由框架固定。

### 6.2 课程详情

```text
家长空间 > 课程 > 一起加入运动队
教材                     学习模式                  资源

七步学习       已发布 v1             查看／准备新版本
课文闯关       待审核候选 v2         继续审核
               当前仍使用已发布 v1
```

课程详情同时展示两种模式的内容状态，但全局启用开关集中在设置。进入七步审核或闯关审核时，使用相同的页面外壳、课程标题、返回位置和保存状态，内部审核内容由插件提供。

“资源”按材料和各模式内容版本组织。框架聚合状态并处理实际文件，模式不能各建一套资源管理中心。

### 6.3 模式设置与缺少内容

```text
家长空间 > 设置 > 学习模式
当前：七步学习

七步学习       已接入    当前使用
课文闯关       已接入    选择使用
```

选中目标模式后，显示可学习课程数，以及未准备、待审核、资源缺失等原因。选择全局模式不自动生成内容，也不删除旧版本。当前课程不足以学习时，切换后孩子页显示“这门课的闯关内容还在准备中”，提供“看看其他课程”和“请家长准备”入口。

插件加载失败时，公共课程、孩子管理、设置和记录入口继续可用；学习区域显示重试或请家长处理。没有接入任何插件时，仍能录入教材、管理孩子和设置，并提示尚未提供学习模式。

## 7 插件接入契约

将当前单个 `loadExperience()` 的整应用注册，逐步改成按职责挂载的注册。以下是目标接口职责，名称可在实施时调整，不是当前已实现的 API。

| 接入点 | 插件提供 | 框架保证 |
| --- | --- | --- |
| 身份与兼容性 | 模式 ID、显示名称、版本、可读取的数据版本、需要的设备能力 | 注册、兼容检查、失败隔离 |
| 课程状态适配器 | 指定课程的草稿、候选、发布版本和阻塞原因 | 在公共目录中呈现；支持非当前模式的只读状态查询 |
| 学习主页 | 模式主页组件与当前孩子／课程对应的视图 | 固定应用导航与上下文 |
| 学习会话 | 会话组件、作答处理、恢复与离开处理 | 专注布局、设备服务、可靠保存和退出 |
| 内容准备与审核 | 准备组件、审核组件、草稿校验、教学发布条件 | 独立于孩子全局模式的家长编辑上下文、任务取消、保存与发布 |
| 报告与待办 | 历史报告组件、基础事实适配、待确认项与处理规则 | 统一记录入口、模式标识、授权与历史访问 |
| 可选模式设置 | 模式特有参数及其校验 | 承载在模式设置区域；公共模型和语音配置仍集中管理 |
| 数据和资源适配器 | Codec、迁移、资源清单、删除参与者 | 存储、共享写入队列、事务、清理协调与引用保护 |

框架注入的上下文包括孩子 ID、课程 ID、教材修订、模式 ID、内容版本、授权范围及服务端口。学习上下文要求当前全局模式；家长准备上下文允许指定非当前模式，仍限制在已授权的课程与操作内。

插件只能通过这些端口请求保存、模型、语音、录音和文件操作，不能修改全局导航、孩子选择或其他模式的状态。基础库不要求存在 `S1…S7`、关卡、统一题型、统一掌握等级或统一复习算法。

状态需要分别表达：

- 内容准备：未准备、草稿、待审核；候选可以与已发布版本同时存在。
- 发布版本：当前采用的精确版本，及其固定教材快照。
- 可学习性：可学习，或因插件／兼容性／必需资源等原因阻塞。
- 学习状态：由模式解释的阶段、路径或其他结构。

模式切换时，先停止或完成当前有归属的异步任务，保存旧模式会话和草稿，再提交全局选择并挂载新学习区域。保存失败保留原模式和编辑现场；迟到的网络结果不能写入新上下文。

模式代码未挂载时，其数据适配器仍能参与目录状态查询和删除协调。将来支持移除插件时，必须先保留可用的数据维护适配器，或阻止移除仍有存活数据的实现，不能让卸载造成无人管理的资源和历史数据。

## 8 分阶段迁移计划（历史方案）

| 当前位置 | 目标归属与动作 |
| --- | --- |
| `src/App.vue`、`src/modes/ModeHost.vue` | 建立应用外壳，负责孩子／家长导航和公共路由；模式宿主缩小到学习、准备和报告插槽 |
| 两个 `Experience.vue` 的顶部栏、设置页、家长确认、返回监听 | 提取为应用级实现，删除模式内的重复实现 |
| 七步 `ParentSpace.vue` | 通用概况、孩子管理、课程目录上移；七步报告与确认规则拆为插件组件 |
| 七步 `CourseManager.vue` | 原文／图片与教材身份上移；词汇确认、生成规则、七步审核保留在七步模块 |
| 闯关 `Experience.vue` 的家长部分 | 教材与公共管理上移；题库准备、完整审核、闯关报告拆成插件组件 |
| `src/application/services.ts` 与七步兼容目录 | 公共目录和删除协调器改为应用所有；旧快照读取作为应用持有的兼容适配器，先保持旧数据可读写 |
| `src/components` 中的设置、音频、图片等组件 | 继续复用；公共页面的生命周期由应用掌握，教学相关参数由插件传入 |
| `packages/learning-modes/seven-step` 与 `passage-path` | 保留独立生成、运行、评价、状态和迁移逻辑；不为统一页面重写为同一种引擎 |
| `src/platform` | 保留设备、持久化、内容调用、资源清理等平台服务 |

建议按三批实施，每批均能单独验证：

1. **先固定外壳和公共入口。** 建立相同的孩子与家长导航、设置页和返回策略，把两种学习主页嵌入同一插槽。保持现有教材和学习数据格式。
2. **再拆课程准备和记录。** 建立共同教材编辑与课程详情；七步和闯关各提供准备／审核／报告组件，家长可准备非当前模式。把目录和删除协调的所有权移交应用。
3. **最后优化闯关教学界面。** 聚焦当前关卡、继续学习、任务反馈和会话结算；路径数量、任务节奏和教学规则继续由闯关模块控制。公共数据独立存储若需迁移，另做显式迁移设计与验证。

第一批界面统一并不表示数据边界已全部完成。最终要求框架在没有七步学习界面和运行引擎时，也能管理公共数据并运行闯关；读取旧格式可以保留独立兼容模块。

## 9 验收场景

| 场景 | 可观察结果 |
| --- | --- |
| 七步切到闯关，再切回 | 品牌、孩子、当前课程、一级导航和设置位置相同；教学区域变化；各模式进度分别恢复 |
| 从学习页进入练习并退出 | 两种模式的退出位置和保存提示相同；失败时保留现场；恢复到各自正确会话 |
| 练习中按 Android 返回 | 框架先关闭顶层弹层，再请求模式处理退出；只注册一个应用级监听器 |
| 同一教材准备两种模式 | 只有一门公共课程；两份模式内容、审核状态和发布版本；无需复制课程 |
| 家长准备非当前模式 | 可以生成、审核和保存；孩子端全局模式不被改变；结果不能串写另一模式或课程 |
| 当前课程无目标模式内容 | 显示明确准备状态；不加载另一模式题目，不默默切换课程 |
| 存在新候选版本 | 当前已发布版本继续可学；采用新版本前展示插件声明的进度影响 |
| 学习中查看原文或播放失败 | 模式收到真实辅助／失败结果；证据和推进符合该模式规则 |
| 当前模式变化后查看历史 | 七步报告仍由七步解释，闯关报告仍由闯关解释；不将不同百分比合并 |
| 插件异常或没有插件 | 公共课程、档案、设置和基础记录入口仍可使用；错误限定在相应插槽 |
| 删除课程或孩子 | 所有模式的数据参与协调；共享资源依据存活引用保留；重试不会恢复已删内容 |
| 接入第三种模式 | 通过注册入口、组件和适配器接入；公共导航、设置、课程页不增加按模式 ID 分支的教学判断 |
