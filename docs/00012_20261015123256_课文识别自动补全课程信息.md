# 课文识别自动补全课程信息

建立时间：2026-10-15 12:32:56（Asia/Shanghai）。对应版本：0.1.11 / versionCode 12。

## 行为

点击“识别课文图片”时，在同一次图片识别请求中返回正文、课文标题和教材或单元信息。标题保留图片上的原始名称；教材或单元仅组合图片明确显示的教材名、册次、Unit、Lesson 等，以 ` · ` 分隔。无法从图片确认的字段留空，不依据课文内容或常识猜测教材出处。

| 当前字段 | 识别后的处理 |
|---|---|
| 标题或教材信息为空 | 自动填入对应识别结果，可继续编辑 |
| 字段已有内容且与识别结果不同 | 保留已有内容，在字段下展示识别建议及单独的采用按钮 |
| 图片未提供该字段 | 不补写已有内容；空字段继续留空 |
| 原文为空 | 自动填入正文 |
| 原文已有内容 | 展示新的识别正文，由家长决定是否替换 |

标题必填，教材或单元选填。确认勾选文案包含标题、教材或单元与原文；修改其中任一字段、重新识别或采用建议后，需要重新勾选。确认原文后仍按原有流程整理词汇、生成与审核课程。识别结果不自动推进步骤。

自动填入和手动修改均使用已有草稿保存机制。未采用的识别建议只在当前编辑过程展示，切换或新建课程时清空。已进入后续步骤的旧课程不自动重新识别或修改。

## 数据与接口

课文识别输出扩展为 `{"title":"…","subtitle":"…","text":"…"}`。正文必需且不超过 6000 字符；标题最多 100 字符，教材或单元最多 120 字符。两个信息字段缺失、类型错误或过长时忽略对应字段，不阻断有效正文；支持旧的仅含 `text` 的响应。

继续使用可配置的图片模型与现有 JSON 模式，不增加识别请求次数，不增加课程快照字段或数据迁移。教材词汇表识别协议保持不变。
