版本说明：本文记录 0.1.3。按用户最新要求，0.1.4 取消预装音频，由用户配置并生成，详见 [无音频安装包设计](00006_20261013210250_用户配置生成课程音频与无音频安装包.md)。以下预制资源仅作为历史材料归档。

应用版本：0.1.3；Android versionCode 4。建立时间为文件名所示 Asia/Shanghai 时间。

本说明替代 0.1.2 中“学习时合成并放入通用缓存”的方案；供应商协议、Key 加密及音色设置仍沿用 [AI 语音配置设计](00004_20261013190848_AI语音配置与缓存设计.md)。实施结果见 [修复验证](../issues/00005_20261013203408_课程音频长期保存修复与验证.md)。

## 1. 课程拥有音频

课文音频是课程资源，与课程 ID、正文版本、资源 ID、原文、音色版本和文件校验值关联。试听音频可使用可淘汰缓存；学习时读取课程资源，不自动请求转语音。

内置“一起加入运动队”随 APK 提供 MiMo mimo-v2.5-tts / Chloe 的 **44 段 WAV、8,004,496 字节**。资源覆盖全部 15 个对话话轮、3 段整段示范、词汇朗读及 25 个听写句子；相同原文只保存一份，多个场景共享。安装后不需要 API Key 或网络即可学习。

资源定义：[course-speech.ts](../src/course-speech.ts)。0.1.3 历史资源：[归档清单](../artifacts/course-audio-samples-0.1.3/manifest.json)及同目录 WAV。清单包括实际原文、相对文件名、字节数、SHA-256 和非敏感生成参数；不含供应商 Key；该归档不参与新版构建。

课程正文版本仍为 0.1.0，教材和练习不变。音色版本独立，不修改已有学习事件、能力证据或课程核对记录。此清单是首版运行资源格式 1，不冒充完整设计的 schema 2.0.0 Lesson Package、审核签名或正式资源授权。

## 2. 持久化与资源身份

Android 首次读取时将随包音频导入应用私有 filesDir/course-audio，之后直接读取课程文件。它不位于 Android cacheDir，也不属于 speech-audio 试听 LRU，不受 128 MiB 缓存淘汰、清理试听缓存或 API 配置删除影响。

课程资源目录以课程 ID、正文版本及全部“资源 ID / 原文”清单的摘要定位；不同正文或课程版本隔离。音色版本由协议、端点、模型、音色、风格的合成请求指纹定位，排除 Key 和播放速度。文件名使用原文摘要，索引同时记录实际音频 SHA-256 和字节数。

每次读取核验文件长度与摘要，损坏项标为未就绪并提示修复，不把缺失音频自动转换成新的收费请求。播放器继续支持 0.5–1.5× 语速，保持 pitch=1；变速不会产生另一份音频或触发生成。

多个学习档案共享课程资源。删除一个学习档案不删除课程音频。家长可确认“恢复内置课程音频”，移除该课自生成的音色版本并重新导入安装包自带版本，其他课程与学习记录保留。

长期保存指课程文件没有缓存淘汰或 TTL。内置版本可随同一 APK 重新安装恢复；用户自行生成的版本仍受卸载、清除应用数据或设备损坏影响。当前未实现自生成课程音频的导出、跨设备恢复或云备份，不宣称这些能力已交付。

## 3. 显式整课生成与安全替换

家长选择服务、模型、音色和风格，先“保存并试听”，确认后点击“生成所选音色的整课音频”。该按钮保存当前填写的配置并开始整课任务；单纯保存设置或试听不会替换课程音频。

生成按清单顺序处理，提供进度和暂停按钮。已生成且校验通过的同版本资源直接跳过；旧版试听缓存存在有效对应音频时可复用。新请求直接写入课程拥有的暂存文件，校验可播放时长后封存，再更新课程索引，不经过试听 LRU。

旧整课音频在新音色生成期间继续可用。新版本全量校验完成后再切换课程所用音色；失败、暂停或进入后台只停止任务，已完成文件保留，下次继续缺失项。没有旧版本的课程可使用已完成片段，缺失片段要求家长继续准备。

课程索引和当前版本选择各使用两个带校验和的文件槽及递增 revision。写入新槽并同步后读取最高有效版本；写入中断时仍有旧槽可恢复。两个槽同时损坏时报告错误并保留资源，不静默清空。原有音色文件不会被自动淘汰。

生成期间阻止修改配置和试听，避免请求参数混用；课程播放仍可使用原版本。应用进入后台、开始录音或显式暂停会取消生成；它没有后台自动收费重试。移除 Key 后课程播放仍可继续，生成新版本时才需要有效服务配置。

## 4. 开发机预制与验证

~~~powershell
# 从 .env 读取凭据，逐段生成；Key 不写入清单
npm run audio:generate

# 再次执行会核验并复用已有资源，不重复合成
npm run audio:generate

# 先完成资源生成，再执行构建
npm run android:debug
~~~

[生成工具](../scripts/generate-course-audio.mjs)保持已完成文件及校验值，不自动重试失败请求，也不覆盖不同指纹的已预制音色。当前内置输出目录固定为 starter；未来完整课程包导入与版本发布属于原设计的后续范围。

原生入口：[CourseAudioSpec.java](../android/app/src/main/java/cn/lingonest/app/CourseAudioSpec.java)、[CourseAudioStore.java](../android/app/src/main/java/cn/lingonest/app/CourseAudioStore.java)、[LingoNativePlugin.java](../android/app/src/main/java/cn/lingonest/app/LingoNativePlugin.java)。界面入口：[SpeechSettings.vue](../src/components/SpeechSettings.vue)、[useSpeech.ts](../src/useSpeech.ts)。

合成文字直接来自已核对原文，没有经过聊天模型改写。音频为 AI 合成产物，当前验证了文件格式、完整性及资源覆盖；未自动证明逐字朗读准确率、口音或教学效果，家长仍应实际回听。
