## 参考原则与判断

多邻国公开的教学方法强调交互练习、从简单到复杂、结合个人表现安排难度，并在不同语境中使用学到的内容，见[官方教学方法](https://blog.duolingo.com/duolingo-teaching-method/)。其路径设计将复习嵌入前进路线，见[官方路径设计](https://blog.duolingo.com/new-duolingo-home-screen-design/)。[官方间隔复习说明](https://blog.duolingo.com/spaced-repetition-for-learning/)还将回想、错误复访和逐步拉开间隔联系起来。

当前闯关已具备短轮次、交流目标、理解／听辨／组句／填空题、到期与薄弱复习、有限补练及跨日独立证据。骨架适合继续发展。进一步优化的重点是让这些环节构成连贯的课程体验，并验证学会的表达能在变化的情境中使用。

## 本轮落地规则

### 新目标得到逐步减少的支持

调度先读取当前孩子在准确课程、包修订和目标下的实际作答，再决定哪些目标是本轮首次接触。关卡表中的 `newGoalIds` 表示课程的引入位置，不能替代孩子的实际学习状态。

首次接触的目标先安排理解题。该轮已选择组句和填空时，组句必须先于填空；没有组句题或必要覆盖已占满预算时，仍保持理解在回想前，不生成未审核题目。不同目标可以相互穿插。

### 旧目标先回想，再巩固

已学目标的重练先给一次独立作答机会，再安排相关支架和答案反馈。需要回想的目标优先独立填空。看过答案的后续同目标作答仍算巩固，不追溯修改先前提交。

这一规则也适用于未完成但已接触过部分目标的旧轮次被封存后再开始：已接触的目标可以复习，尚未接触的目标继续获得理解和组句支持。重练不增加路径完成记录，独立证据仍按原有时间间隔与可信时钟规则计算。

### 已审变式有计划地轮换

新一轮基础题在满足目标覆盖和所需难度后，优先选择当前孩子未作答的变式；都作答过时优先较久未练的变式。以持久作答顺序判断最近程度，时钟回拨不改变此排序；相同优先级仍由随机种子决定。

最终题序必须保留选题时确定的首次独立题，避免把另一道同目标题排到前面并先展示答案。轮换范围按孩子、课程、包修订、题目隔离，其他孩子及旧包的记录不会改变本人的题序。

新会话记录 `schedulerVersion: "4"`，旧版冻结队列继续原样恢复。本轮仅修改闯关核心的调度与版本接受范围，没有扩展公共框架的教学契约。

## 下一阶段的课程建设优先级

1. **把目标贯穿多次短课。** 一篇课文作为内容单元，交流目标组织关卡，短课提供不同层次的接触与复习。可以呈现“初识—练表达—换情境—隔天回访”，具体次数随表现调整。继续保留“练过”的路径事实，同时使待巩固内容有明确、可进入的推荐位置。
2. **建立有迁移价值的题库。** 同一表达改变任务与交际情境，干扰项对应可解释的误解；审核时检查是否只是换题干复述相同问题。先用少量课文建立家长能判断的质量样本，生成器按样本扩展。
3. **形成听说与语境使用的闭环。** 根据目标安排听懂、选择回应和角色应答。口语评价及开放回答先明确完成条件和证据来源，再接入设备能力；课程数据与规则继续属于闯关模式。
4. **让结算指向下一次学习。** 说明本轮练了什么交流用途，指出一两个值得巩固的目标，并给出合适的后续短课。积分、徽章和连续学习记录排在这些教学闭环之后。

例如“邀请别人加入”可以经历：理解课文中的邀请 → 用词块组成邀请 → 无选项补全 → 后续短课在课文已知的乒乓球队情境中主动邀请 → 隔天先独立回想。情境变化需要明确标为新情境，仍使用孩子已接触的表达和词语。

以上课程层级、语义质量标准、口语与结算扩展属于设计建议，本轮代码落地的是梯度、重练与变式轮换。实际短课数量、错误后支持强度和迁移练习频率需要儿童试用验证。现有测试验证规则一致性和交互结果。
