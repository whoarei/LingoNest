# 英语小窝 0.2.0

建立时间：2026-10-25 00:12:07（Asia/Shanghai）。包名 `cn.lingonest.app`，Android 构建号 `18`，最低 Android 7.0（API 24），目标 API 36。

## 本版变化

- 新增“更多 → 应用更新”公共入口，学生和家长均可查看版本、手动检查、下载新版及打开系统安装界面。
- 应用启动后在后台检查新版本，不阻塞首页和学习；仅在空闲的学习首页提醒，专注练习过程中不弹出更新提示。
- 自动检查成功后 24 小时内不重复检查，失败后适当退避；点击“稍后”可暂缓同一版本提醒，手动检查随时可用。
- 安装前保存当前内容并停止播放；从教材编辑页进入后，返回时恢复编辑状态。准备安装期间阻止离页，避免安装器打断新练习。
- 下载过程显示进度并支持取消；核对安装包完整性、应用身份、设备兼容性和正式签名，失败后可重试，已校验的安装包可复用。
- GitHub Release 随正式 APK 发布在线更新清单，沿用正式签名及 CI 检查，并防止较旧版本覆盖最新发布指向。项目内新增 LingoNest 发布 skill，统一版本准备与 CI 发布流程。

## 安装与更新

**0.1.16 尚无应用内更新入口，需手动下载本版正式 APK 覆盖安装一次。** 本版沿用 0.1.16 的正式发布证书，从本版开始可通过应用内更新获取后续版本。旧 Debug 测试包与正式证书不兼容，应用不会自动卸载或清空旧数据。

下载本 Release 的 `lingonest-0.2.0-release.apk`。Release 同时提供 `update.json`、`SHA256SUMS.txt` 和 `signing-certificate-sha256.txt`。

Android 安装仍需用户允许安装来源并在系统安装界面确认；“安装界面已打开”不代表升级已经完成。应用内下载不保证在进程被系统回收后继续运行。

应用不预装课程音频和开发者凭据，家长继续按原方式配置服务并准备课程。本版未调整学习数据格式。真实设备的覆盖安装、厂商授权页面及升级后数据保留尚未实测，不将浏览器或原生单测结果视作真机升级验收。
