# 英语小窝应用图标设计

建立时间：2026-10-13 17:59:51（Asia/Shanghai）  
首次采用版本：Android 0.1.1（versionCode 2）。

## 设计

以“金色小鸟坐在书本形鸟窝里”为主图形：小鸟延续应用首页的陪伴角色，展开的书本表达学习，书本下方的弧线表达小窝。采用森林绿背景、浅金色身体、米白书页及暖橙色鸟喙，不放文字，保证小尺寸识别。图形使用可编辑矢量路径绘制，沿用应用现有插画语言，替换 Capacitor 的默认启动图标。

## 平台资源与维护

自适应图标分离全幅底色和透明矢量前景，使用 108dp 画布；主要图形位于中央区域。API 33 及以上另提供 monochrome 层，支持用户启用主题图标时的系统着色。平台要求参考 [Android 官方自适应图标说明](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive?hl=en)。

Android 旧版位图覆盖 mdpi、hdpi、xhdpi、xxhdpi、xxxhdpi，对应 48、72、96、144、192 像素；另输出圆形位图。网页 favicon 使用同一图形。应用内原有首页插画继续作为较大场景插画使用。

修改主定义后在仓库根目录运行：

```powershell
npm run icons:generate
npm run android:debug
```

[生成脚本](../scripts/generate-icons.mjs)从同一几何定义生成 SVG、Android VectorDrawable、自适应配置和位图；位图使用项目现有 Playwright 与本机 Edge 渲染，不增加图像生成服务或外部图片依赖。

验证结果见 [图标替换与真机验证](../issues/00003_20261013175951_应用图标替换与真机验证.md)。
