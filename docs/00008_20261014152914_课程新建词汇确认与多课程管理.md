# 课程新建、词汇确认与多课程管理

建立时间：2026-10-14 15:29:14（Asia/Shanghai）。对应工作区版本：0.1.5。

本轮落实家长课程管理流程：拍照或填入文章 → 识别并确认原文 → 整理并确认重点词汇 → 生成学习内容 → 家长审核 → 启用课程 → 准备音频 → 指定孩子学习。模型配置仍在设置里，课程音频的生成、暂停续作及删除移至家长空间的课程管理。

## 入口与课程库

左上角图标单击切换家长空间，进入“课程”。课程库包含内置样例及最多 30 个自建课程（含草稿）。没有孩子档案时也可以准备课程；指定学习课程需要先建立孩子档案。

浏览或管理某一课程不自动改变孩子正在学习的课程。只有点击指定学习按钮后，当前孩子才切换到已启用课程。课程内容和音频按设备共享，课程选择、练习恢复点和学习记录按孩子与课程隔离；切回原课程保留原有进度。其他孩子的课程选择不受影响。

## 新建流程

| 步骤 | 家长操作与校验 |
|---|---|
| 原文 | 填写标题；拍照、从相册导入或直接粘贴英文。图片可放大、旋转、移除及调整顺序；主动点击识别。已有文字时，识别结果先单独展示，家长决定是否采用 |
| 原文确认 | 编辑英文原文、角色与顺序；未识别处使用 `[待校对]`，必须修正；勾选核对确认后继续。原文最长 6000 字符、60 个段落，每段最长 2000 字符，并需包含英文 |
| 重点词汇 | 拍照或相册导入教材词汇表，也可让应用依据确认后的原文生成。两种来源可混用，按词条忽略大小写去重；保留来源标签，可增删、编辑词条、中文释义及例句、取消选择 |
| 词汇确认 | 至少选择一个词条，选中词条必须有英文词条和中文释义；最多 80 条。空白未选条目在确认时清除 |
| 生成内容 | 使用确认后的原文和词汇请求课程生成模型；失败、格式错误或主动停止都保留已保存草稿，重试不需要重新输入原文 |
| 审核 | 编辑逐段中文释义、理解题、正确选项及解释、受控情境应用题与可接受答案；预览七阶段练习；勾选审核确认后才能启用 |
| 启用与使用 | 启用后课程内容冻结，不允许直接修改已有题目及答案；修订需新建课程。课程内准备音频，再明确指定当前孩子学习 |

草稿会延时自动保存，也提供显式保存。确认步骤先保存，再进入下一步。返回原文或词汇重新整理会清除下游生成内容，避免旧题库与新原文混用。退出内容处理或主动停止后，迟到结果不能覆盖当前草稿。

## 七阶段学习内容

模型只生成教学草稿：中文释义、理解题与受控应用题。本机根据审核通过的数据构造完整题库，固定保留读懂故事、词汇、句型、朗读、背诵、默写、迁移七阶段，复用已有评分、人工口语确认、掌握证据和复习规则。

原文按段落/话轮解析，角色使用 `Name: text`；按原文顺序装入 A/B/C 最多三个区块，每块最长 2400 字符。至少需要一个可排序的多词句，全文最多 80 句。词汇阶段使用家长选中的重点词汇，句型与默写依据原文，朗读与背诵根据实际区块生成。迁移阶段采用明确答案范围的应用题，尚不支持自由写作评分或自动发音评分。

生成数据在进入审核及启用时执行结构校验：释义数量与原文段落一致；理解题 1–8 道，每道 2–4 个不同选项及有效答案索引；应用题 1–8 道，每题 1–5 个明确英文答案。结构校验不能替代家长对事实、难度、中文释义和答案合理性的审核。

## 课程音频与设置

设置保留语音服务、API Key、音色、语速、试听以及新加入的文字识别和课程生成模型配置。课程页提供整课音频生成、暂停/续作、试听及删除资源。缺少配置时链接到设置，返回恢复课程草稿。

音频规格依据各课程题库动态构造，相同朗读文本在本课内去重。原生资源继续以课程 ID 与版本分开保存，生成或删除自建课程音频不影响内置课程。课程管理和学习页共用模型配置，但独立选择所管理的课程；后台生成时限制课程切换。

## 数据与原生接口

`LocalState.formatVersion` 升为 2，新增课程库、按档案的学习课程选择及按课程版本的核对记录，练习恢复点新增 `courseId`。读取真实旧版 formatVersion=1、内置 courseVersion=0.1.0 快照时迁移确认与恢复记录到内置课程，保留档案和历史作答。SQLite 原子快照、revision 检查与容量上限继续使用既有机制；这仍不是设计文档的正式 schema 2.0.0 Lesson Package。

自建课程、题目、题族和知识点使用课程 ID 命名空间。加载快照时验证课程、孩子及练习引用，审核中和启用后的题库必须与原文、词汇及教学草稿重新构建结果一致，拒绝不一致包及未知状态格式。

Android `CourseContent` 插件负责调用系统相机/相册、图片读取和显式模型请求。每组原文/词汇图片最多 6 张；单图输入不超过 20 MiB，按 EXIF 方向修正并压缩为最长边不超过 1600 像素的 JPEG，保存到应用私有 `course-images/`。只有规范的私有图片路径可以被读取或上传。移除图片引用暂不清理已有私有图片文件，尚未提供课程删除及孤立资源清理。

识别与课程生成分别配置 HTTPS 服务地址、模型及加密保存的 Key。请求使用 `POST <baseUrl>/chat/completions`、Bearer 认证及非流式响应；图片识别使用图片 data URL，纯文字请求使用字符串消息内容。响应读取 `choices[0].message.content`，解析有界 JSON；接口依据 [Chat Completions 官方协议](https://developers.openai.com/api/reference/resources/chat)。供应商需要支持该接口及选定模型的图片能力，本轮未验证所有兼容服务。

Key 不返回前端、不写入学习快照、更换服务域名需重新填写。只有主动识别/生成时上传所选图片或课文，不上传孩子录音和学习记录。图片和课程快照未做数据库静态加密。网络超时、非成功状态、异常响应和取消均保留已保存草稿，界面不展示原始服务错误正文。

实现入口：[CourseManager.vue](../src/modes/seven-step/components/CourseManager.vue)、[course-library.ts](../src/course-library.ts)、[content.ts](../src/content.ts)、[CourseContentPlugin.java](../android/app/src/main/java/cn/lingonest/app/CourseContentPlugin.java)。验证结果见[课程创建与独立音频验证](../issues/00009_20261014152914_课程创建与独立音频验证.md)。
