# 课程删除、详情页面与设置返回规则

建立时间：2026-10-14 16:07:47（Asia/Shanghai）。当前版本：0.1.6。

0.1.7 已按新需求将删除改为无确认的可恢复删除，并增加列表滑动操作，见[滑动删除与恢复规则](00010_20261014162522_课程滑动删除与已删除恢复.md)。本文删除确认及永久资源清理部分保留为 0.1.6 历史，页面导航与设置返回规则继续有效。

## 课程列表与详情

家长空间“课程”首先显示课程列表及新建入口，不在列表下方展开课文或音频。点击课程进入独立详情页面，草稿显示其当前编辑步骤，已启用课程显示使用操作、音频与原文。新建成功直接进入新课程编辑页。

详情顶部提供“返回课程列表”；Android 系统返回键执行相同导航。返回前保存草稿；保存失败时停留在当前详情并提示，避免丢失编辑。正在处理内容时停止请求并保留草稿，音频生成暂停后返回列表。家长导航切换栏目或显式点击“课程”会进入列表；从设置返回则恢复原课程详情或原列表。

## 删除课程

自建草稿及已启用课程都可从详情页删除，内置样例保留。删除前展示课程名称、影响范围及不可撤销提示，勾选确认后再执行成人防误触确认。

删除范围包括课程定义、该课程在所有孩子档案中的核对记录与课程选择、练习恢复点、作答、人工确认及本课相关暴露记录。正在学习本课的孩子回到内置课程；未核对内置课的孩子仍需核对才能练习。孩子档案、其他课程及其学习记录、模型配置保留。

删除操作先以既有原子快照机制提交课程移除和资源清理待办，成功后才清理本课的课程音频、当前引用的教材图片及学习录音。快照保存失败时保留课程且不清理文件。多课程共同引用的图片或录音保留；混合课程暴露事件仅移除被删除课程的目标，其他目标保留。

资源清理失败时课程不会重新出现，待办保留于 `pendingCourseDeletions`，下次启动自动重试，课程列表也提供手动重试入口。清理接口验证私有目录路径，允许文件已不存在以支持重试；防止草稿自动保存把已删除课程重新写回。设置、孩子档案等数据不参与课程资源清理。

0.1.5 快照缺少新待办字段时自动补空数组，仍使用 `formatVersion=2`，不改变已有课程 ID、题目 ID 或学习进度。此清理机制处理删除时课程仍引用的资源；之前已从图片列表移除的孤立文件，尚未建立全局清理器。

## 设置与系统返回

设置记录进入前的页面，保留家长空间身份、栏目与选中的课程详情。页面返回按钮、家长身份下设置页的左上角按钮、Android 系统返回键都回到原家长页面；学习空间进入设置则返回原学习页面。

Android 使用 [OnBackPressedDispatcher](https://developer.android.com/reference/androidx/activity/OnBackPressedDispatcher) 与生命周期关联的 [OnBackPressedCallback](https://developer.android.com/reference/androidx/activity/OnBackPressedCallback) 将系统返回交给前端。原先没有前端返回处理，系统会退出 Activity；现在优先关闭原图或确认交互、返回设置来源、返回课程列表、回到家长概况，再返回学习空间。练习中返回仍先显示保存进度与退出确认。只有学习首页根页面返回才将应用移到后台。
