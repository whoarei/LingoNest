## 学习顺序与证据

路径完成表示练过，稳定表现表示积累了模式规定的独立证据。首轮诊断、使用过相关辅助的作答、补练和同轮看到答案后的同目标作答，都不直接作为稳定表现证据。评价仍采用模式内的可解释规则；不将规则测试通过等同于实际学习效果已经得到验证。

| 情况 | 新一轮的安排 |
| --- | --- |
| 新目标 | 先理解，再组句和回想；需要回想的目标保留无选项作答覆盖 |
| 已学且要求回想的目标 | 优先选择回想题，在同目标的选择、组句及其答案反馈前出现 |
| 不要求回想的已学目标 | 优先选择能产生独立证据的题目，避免只有带支架的练习 |
| 本关已覆盖的旧目标 | 不再重复占用到期／薄弱复习名额，把剩余位置留给其他已学目标 |
| 跨课复习 | 只选当前孩子、当前模式、已实际作答且仍可用的当前发布版本；保留准确来源与音频 |

当前新包默认规则版本为 `2`：基础题量由覆盖要求在 4～6 题间选择，每关最多两个新知识块，到期和薄弱复习各预留一个位置，跨课最多一题，最多追加两道补练。必要目标覆盖优先于比例。旧包继续遵循其审核过的题量预算。

新会话记录 `schedulerVersion: "3"`；保存过的 `1`、`2`、`3` 版队列均按实际题目、顺序、输入和反馈恢复，不重新调度。本次未改写已经提交的作答，也未降低稳定表现门槛：首轮诊断排除后，至少三个相隔 24 小时的独立成功轮次才进入稳定状态。

## 辅助的作用范围

| 操作 | 影响范围 | 主动查看记录 |
| --- | --- | --- |
| 当前题的提示 | 当前来源课程、包修订、目标 | 绑定当前题，区分提交前后 |
| 当前题的原文 | 正在显示的来源包中，本轮涉及的目标 | 绑定当前题，区分提交前后 |
| 暂停后阅读本课原文 | 实际显示的本课包中，本轮涉及的目标 | `questionId: null` 表示整课阅读，不伪造某题的查看时点 |
| 提交后的参考答案 | 当前目标的后续作答 | 属于反馈产生的巩固条件，不算主动点击提示 |

整课阅读向运行器显式传入实际显示的 `courseId` 和 `revision`。运行器验证该来源属于会话主课或冻结队列；提示不接受另一个来源。暂停在跨课题时阅读本课，不能把另一课程的目标误记为已暴露。已有提交事实不因后续阅读而被追溯修改。

同一题的提示、原文各计一项；整课原文按会话、来源版本另计一项。报告分别展示主动查看次数与受到辅助的作答次数，不能将二者互相替代。

## 交互与恢复

提交成功后焦点移动到“继续”，下一题移动到题目标题，完成后移动到结算标题。普通输入和自动保存不抢焦点；隐藏的工作区不移动焦点，退出后恢复同一道题也重新定位，收起原文后返回当前题或反馈。填空输入最多 2000 字符，与核心作答校验一致，避免粘贴过长内容后无法保存或退出。

播放已有课程音频时提供固定在视口底部的“停止播放”，长原文滚动到底部也可立即停止。停止不提交答案、不移动题序，也不将主动取消显示为播放失败。播放仍通过公共语音能力端口完成；模式仅拥有自己的播放状态和取消代次，卸载时释放自身资源。

内容准备页明确显示未保存的审核修改。显式保存或正常离页都会提交最新审核状态；失败保持编辑现场，既有自动保存和离页拦截继续有效。

## 教材变化与候选题库

候选题库必须与当前教材完整快照匹配，包括课程、教材修订、标题、原文话轮和图片。教材变化后，旧候选保留为历史，不能继续进入审核编辑、不能阻挡新生成，也不再作为首页或课程概况的“待审核内容”。新生成从当前教材建立独立候选，审核确认从未确认状态开始。

同一教材只将最新的有效候选视为当前准备内容；最新候选发布后，早先保留的候选不能继续让课程显示待审核。资源列表区分当前已发布、历史发布、当前候选、历史候选及过期候选。历史资源继续参与资源保留和删除清理，不能因候选失效直接清理文件。保存与发布的服务端口仍在公共写入队列中重新核对教材，界面过滤不能代替写入校验。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| 模式核心 `scheduler/runtime/progress/state` | 题序、独立证据、辅助范围、状态校验及版本恢复 |
| 模式适配 `material.ts` | 将公共教材转换为模式来源，并筛选可审核候选；不读取七步数据 |
| 模式适配 `learning-audio.ts` | 按当前孩子、可用课程、版本和冻结会话计算音频检查范围 |
| `useExperience` 与模式组件 | 调用事务、播放、审核保存及焦点反馈，不重写公共目录 |
| 框架与平台 | 公共教材与孩子、导航和离页、原子文档保存、语音设备与资源能力 |

开始新轮前只检查当前课及当前孩子有作答历史的可用发布版本；存在活跃冻结会话时只检查主课与队列引用。提交时复核这些资源，不逐次扫描其他孩子或无关课程的音频。运行器仍复核公共课程可用性与资源状态，音频范围筛选不扩大跨课资格。

公共框架不新增闯关题型、辅助范围或稳定判断字段；七步教学核心与历史记录不参与闯关调度。当前结构保留一个公共框架和两个独立教学核心。
