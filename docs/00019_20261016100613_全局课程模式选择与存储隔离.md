# 全局课程模式选择与存储隔离

建立时间：2026-10-16 10:06:13（Asia/Shanghai）。承接[课程设计模式独立化方案](00017_20261015140801_课程设计模式独立化方案.md)。

## 1. 设置入口与产品规则

点击右上角齿轮，进入通用“小窝设置”，在“课程模式”区域查看或切换。学习空间和家长空间共用该设置入口；家长底部导航保留概况、确认、报告、课程四项。2026-10-16 根据产品调整移除了原独立“模式”导航与概览快捷入口。

- 每台设备保存一个 `activeModeId`，作用于本机所有课程和孩子档案，不在课程内分别选择。
- 实际切换经过家长操作确认；重复点击当前模式不写入设置，也不重置进度。
- 当前正式注册表提供“七步学习”和“课文闯关”两个真实体验。七步继续作为默认模式，新增模式不会自动改变已有设备的选择。
- 切换保留各模式内容与学习记录。当前模式未生成、草稿未完成或待审核时，提示家长生成并审核，孩子不能开始学习，也不会自动改用七步内容。
- 设置及内容保存在本机，不提供跨设备同步。其他浏览器页面的过期写入会被 revision 检查拒绝，需要刷新后重试。

七步模式的已发布课程继续视为可学习内容，原有孩子与课程原文确认仍按原规则执行；新增全局选择不要求家长重新生成或审核已有七步课程。

## 2. 公共控制与模式职责

| 位置 | 职责 |
|---|---|
| [mode-selection.ts](../src/platform/mode-selection.ts) | 独立加载全局设置；校验已安装模式；执行切换准备并保存单一选择 |
| [ModeHost.vue](../src/modes/ModeHost.vue) | 等待设置就绪；懒加载并挂载所选模式；切换时卸载旧体验；处理未知模式或加载失败 |
| [CourseModeSettings.vue](../src/components/CourseModeSettings.vue) | 通用单选列表、范围说明、失败提示；家长确认由调用方提供 |
| [ParentModeSettings.vue](../src/components/ParentModeSettings.vue) | 通用设置中的家长确认与模式选择；同样用于模式无法加载时的显式恢复 |
| [availability.ts](../packages/learning-modes/availability.ts) | 通用 `missing / draft / review / ready` 就绪状态，只有 `ready` 允许学习 |
| [CourseModeNotice.vue](../src/components/CourseModeNotice.vue) | 缺少内容、草稿和待审核提示；生成审核动作由所属模式接管 |
| [seven-step/course-access.ts](../src/modes/seven-step/course-access.ts) | 将七步课程状态映射为公共就绪状态，不把七步课程当作其他模式产物 |
| [seven-step/useLearning.ts](../src/modes/seven-step/useLearning.ts) | 七步学习入口检查全局模式和就绪状态；切换前保存当前恢复点 |

公共层只认识身份、就绪状态、生命周期和保存机制。阶段、题型、提示、评分、复习、生成提示词和审核细节分别由所属模式实现。两种模式提供完整且不同的学习体验。

## 3. 切换事务与生命周期

模式体验通过 `useModeSelection()` 获取全局只读状态，使用 `beforeSwitch(async () => ...)` 注册准备函数，在作用域销毁时注销。准备函数应停止自己拥有的媒体，完成当前恢复点或草稿保存，失败则抛出异常。

顺序为：家长确认 → 锁定当前界面 → 等待全部准备函数 → 持久化新选择 → 更新 `activeModeId` → 卸载旧体验并加载新体验。准备或设置写入失败时，保留当前模式、当前界面和恢复数据，显示失败原因。

七步准备函数在录音、保存或音频生成尚未完成时拒绝切换；保存未提交的文本、选项、提示和录音路径，不新增作答事实。退出会话后解绑活跃会话标识，恢复点写入同时检查当前孩子、课程和题队列，防止切换上下文后覆盖旧恢复点。

从课程编辑进入通用设置时，编辑器保持挂载并保留编辑课程 ID，返回后恢复原编辑页面；在设置内真正切换模式时，仍执行该编辑器的切换准备与草稿保存，失败则保持当前模式。家长页内部导航和返回学习空间继续使用离开检查：先保存，再更新页签或卸载。等待保存期间的新修改会继续保存，确认最新版本落盘后再离开；已保存的编辑器卸载时不再追加重复写入。原修复见[两项 P2 修复验证](../issues/00028_20261016105437_全局模式切换两项P2修复验证.md)，入口调整验证见[课程模式设置入口调整验证](../issues/00031_20261016113007_课程模式设置入口调整验证.md)。

未知已保存模式不会自动回落到默认模式。损坏或不支持的设置不被覆盖，界面提示重新打开；已有课程快照保持原样。

## 4. 存储隔离与兼容

| 数据 | 浏览器 | Android |
|---|---|---|
| 七步课程、档案、学习事件、恢复点 | 原 `lingonest.local.v1` | 原 `loadState/saveState`，原 `lingonest-state.db` |
| 全局模式选择 | `lingonest.mode-settings.v1` | 新 `loadDocument/saveDocument`，key 对应独立数据库 |
| 后续模式载荷 | 该模式自己的 codec key | 同一 key 对应独立数据库 |

公共 [SnapshotRepository](../src/platform/snapshot-repository.ts) 默认使用按 key 隔离的原生文档接口。只有七步仓储显式启用历史槽。新数据库名为 `lingonest-document-<key 的 SHA-256>.db`，复用原快照的事务、校验和、容量限制及 revision 并发检查，不会寻址历史数据库。

首次升级没有全局设置时，单独持久化 `seven-step`，之后即使注册表默认值变化，也不会替已有用户切换模式。此操作不写入七步快照。

七步 `formatVersion = 2`、v1 → v2 迁移、课程/题目 ID、事件结构、评分策略、图片/录音和音频资源键保持原样。没有把旧作答改写成另一模式的进度。

## 5. 接入下一真实模式

1. 提供独立身份、核心、体验组件和 codec key，注册到 [registry.ts](../src/modes/registry.ts)。
2. 在通用设置入口复用全局设置组件及家长确认机制，注册并注销切换准备函数。
3. 按稳定 `courseId` 查询本模式的发布状态；不存在就提示生成，审核完成才提供学习入口。不得把旧七步包当作本模式内容。
4. 使用独立载荷和资源命名空间，保存本模式自己的会话、评价与恢复数据。
5. 接通共享教材和档案目录。2026-10-17 已通过七步边界内的兼容适配器提供公共读取和共享管理命令，保持课程和孩子身份；历史目录尚未迁移。共享写入、材料课程选择和跨模式删除的实现边界见[共享课程目录与跨模式数据协调](00021_20261017063925_共享课程目录与跨模式数据协调.md)。

2026-10-17 已接入课文闯关的独立核心、共享目录、学习页面、家长生成审核和正式注册，见[课文闯关方案](00020_20261016233511_课文闯关课程模式方案.md)及[页面接入验证](../issues/00036_20261017074456_课文闯关页面接入与正式注册验证.md)。端到端测试直接覆盖真实双模式往返和闯关生成学习；另保留拦截注册表的测试体验，专门验证宿主事务故障，该占位体验不进入生产构建。

验证记录见[全局课程模式实现与兼容验证](../issues/00026_20261016100613_全局课程模式实现与兼容验证.md)。
