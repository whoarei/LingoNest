# 已删除课程彻底删除与入口隐藏

建立时间：2026-10-14 17:00:29（Asia/Shanghai）。对应版本：0.1.8。

正常课程列表的删除仍是可恢复移除。“已删除”中的每门课程新增“彻底删除”，与“恢复课程”并列；列表文案明确彻底删除会清除本课学习记录及资源，无法恢复。延续此前取消确认的要求，此按钮直接执行，不增加勾选、弹窗或成人算术确认。

后续界面简化：列表标签与新建按钮合并到同一工具栏，去掉重复标题及长说明；已删除课程使用紧凑的行布局，显示标题、简短删除日期及并排的“恢复”“彻底删除”文字操作。提示仅保留“彻底删除后无法恢复”。删除、恢复与彻底删除成功后只显示一条短提示，约 2.8 秒自动消失；错误提示与资源清理重试继续保留。数据处理规则不变。

彻底删除仅允许作用于已删除课程，内置课程和正常列表中的自建课程不能直接彻底删除。先原子保存课程移除、所有孩子在本课的作答/确认/暴露记录与练习恢复点删除，以及资源清理待办，再清理本课音频、当前引用的图片和录音。其他课程共同引用的文件保留，混合暴露事件仅移除本课目标，孩子档案和模型配置不删除。

保存失败时课程仍在已删除列表，可继续恢复或重试彻底删除，文件不清理。保存成功后即不再提供恢复或撤销；资源清理失败保留待办，列表提供重试，下次启动也会重试。已移除课程保存在内部清理待办中仅用于资源定位，不作为可恢复课程展示。此前已从课程图片编辑器移除的孤立图片仍不由此功能清理。

没有已删除课程时隐藏“已删除”标签。当恢复或彻底删除最后一门已删除课程后，自动回到正常课程列表并隐藏标签；删除新的课程后标签自动出现。设置返回与原有课程滑动删除保持原行为。

实现：[CourseManager.vue](../src/components/CourseManager.vue)、[course-deletion.ts](../src/course-deletion.ts)、[useLearning.ts](../src/useLearning.ts)。复用原生资源清理及已有持久化待办机制，不新增状态格式版本。
