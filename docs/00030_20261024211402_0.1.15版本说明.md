# LingoNest 0.1.15 版本说明

建立时间：2026-10-24 21:14:02（Asia/Shanghai）。Android 构建号 `16`，包名 `cn.lingonest.app`，源码标签 `v0.1.15`。本次沿用项目既有的 Android Debug 签名，交付可安装的测试版 APK。

## 本版变化

- 闯关每关包含初识表达、换情境用、听说应答三次短课，全部完成后推进下一关。进度分别保存，支持退出、恢复及已完成小课重练。
- 新增明确标注的新情境任务；家长可以按关卡、目标和短课审核、编辑题目及口语回听要点。
- 听辨要求完整播放题目音频；口语支持录音、重录、完整回听与自评。口语只记录练习完成，不自动判断发音或增加答对率。
- 结算列出交流用途与需要巩固的目标，提供下一小课、巩固和隔天回访入口，避免反复强推立即重练。
- 改善新目标梯度、已学目标独立回想、变式轮换、播放取消、小屏与键盘交互，以及权限和保存失败后的恢复提示。
- 孩子、教材、模式数据及删除恢复流程保持各自边界，重录文件纳入所属课程清理清单。

详细规则见[当前课程设计](00029_20261024191849_闯关多次短课情境迁移与听说闭环设计.md)，构建、签名、校验和提交交付范围见[发布验证](../issues/00053_20261024211402_0.1.15提交与APK发布验证.md)。
