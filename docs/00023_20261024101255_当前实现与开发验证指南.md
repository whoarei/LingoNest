建立时间：2026-10-24 10:12:55（Asia/Shanghai）。以当前 `0.1.14` 代码为准。设计目标见[统一应用框架方案](00022_20261017091925_统一应用框架与学习模式插件界面边界方案.md)；本次审核结果见[多轮审核验证](../issues/00045_20261024100937_多轮代码场景与界面审核修复验证.md)。旧文档中的测试数量和安装结果只描述对应日期的版本。

## 使用流程与实际边界

1. 首次启动建立孩子档案。孩子空间固定提供学习、课程和记录；家长通过防误触算式进入管理空间。算式用于避免误触，不是密码或身份认证。
2. 家长在课程中新建共同教材，可以手工输入，也可以在 Android 中拍照、选图并识别后校对。保存或正常离开编辑页时写入教材；识别或保存失败时保留当前草稿。应用进程被直接终止不等于正常离页，未保存的输入可能丢失。
3. 在课程详情中分别准备七步或课文闯关内容，可以准备未全局启用的模式。七步需校对原文、确认词汇、生成并审核学习内容；闯关需核对教材安排和完整题库，必需音频齐备后发布。
4. 学习模式在家长设置中全局选择，作用于所有孩子。切换保留孩子、课程及各自历史，先保存原模式进度；当前课程缺少对应内容时显示准备入口，不替孩子切换课程。
5. 孩子开始练习后进入专注布局。退出保存未提交输入，不计为答错；保存失败停留原位置。家长从错误提示进入设置再返回，同一闯关会话继续使用原题目和输入。
6. 删除课程先移到已删除列表，原内容与进度保留，恢复后可重新选择。只有家长能查看该列表。彻底删除课程或孩子会清理相关模式数据，需输入名称确认。
7. 学习记录按当前孩子、课程和模式查看，每页 50 条，可继续查看较早记录。详细报告由产生数据的模式解释，七步和闯关的进度或掌握率不相加。

当前教材存储仍使用旧七步快照的兼容适配器。内置教材、已发布七步课程，以及已经发布闯关内容的教材保持只读；没有实现发布后直接修改共同原文并自动迁移已有学习内容的流程。需要不同原文时新建教材。修改未发布共同教材会使七步生成草稿失效，过期的闯关候选也不能发布。

七步口语提交后需要家长回听确认；使用过示范的练习与独立尝试分别保留。闯关区分路径完成、首答、补练、主动辅助与长期稳定表现；完成关卡不等于已经掌握。历史会话和发布版本保留自己的题目与材料依据。

## 开发与验证

在仓库根目录安装依赖后执行：

| 命令 | 作用与边界 |
| --- | --- |
| `npm ci` | 按锁文件安装依赖 |
| `npm run dev` | 在 `http://127.0.0.1:5173` 启动浏览器预览；浏览器存储与 Android 设备数据分别保存 |
| `npm test` | 运行教学规则、存储、删除协调与兼容性单元测试 |
| `npm run test:e2e` | 使用本机 Microsoft Edge 和受控原生接口夹具检查页面及场景；自动启动开发服务器 |
| `npm run check:docs` | 检查 `docs/`、`issues/` 编号重复、文件命名和本地 Markdown 链接 |
| `npm run build` | 类型检查、以 Chrome 74 为构建目标生成生产资源，并检查没有预打包课程音频 |
| `npm run android:debug` | 构建网页、同步 Capacitor、构建 Debug APK；需要 Android SDK 和可用的 Java/Gradle 环境，不自动安装到设备 |

Android 原生单元测试可在 `android/` 执行 `./gradlew.bat testDebugUnitTest --offline --no-daemon`，离线执行要求依赖已缓存。APK 构建和原生单元测试也不能代替实际设备交互检查。

课程音频在用户配置后按课程生成，学习时优先使用本地课程资源，不为缺失片段自动发起付费合成。构建目标只负责语法兼容，不自动补齐旧 WebView 缺少的 API；涉及平台 API 的修改仍需兼容检查。旧 API 的开发服务测试可能产生 Vite 热更新客户端日志，需与生产应用行为分别判断。

自动化夹具能检查保存失败、退出恢复、审核、模式切换、长文本与小屏等行为；真实 OCR／模型输出、网络服务、麦克风质量和儿童使用体验仍需实际验收。报告不得把夹具结果写成真人或真机验证结果。
