# 用户配置生成课程音频与无音频安装包

应用版本：0.1.4；Android versionCode 5。建立时间为文件名所示 Asia/Shanghai 时间。

用户明确要求 APK 不附带音频，由自己配置 API 并完成转换。课程音频的长期归属、音色版本和断点生成仍沿用 [课程音频资源设计](00005_20261013203408_课程音频长期资源设计.md)，本版取消其预制音频交付和自动导入部分。验证见 [移除预装音频与首次生成流程验证](../issues/00006_20261013210250_移除预装音频与首次生成流程验证.md)。

## 1. 初始状态与用户流程

APK 内保留课程原文和 44 项去重后的朗读文字清单，不包含 WAV、MP3、预制音频清单、API Key 或自动配置逻辑。首次安装课程音频显示 0 / 44，读取课程或进入学习不会调用合成服务。

1. 进入设置与家长入口，完成防误触题。
2. 在课文朗读选择 AI 语音合成，填写自己的 Base URL、模型、Key、音色和可选风格；MiMo/OpenAI 预设可帮助填写公开参数。
3. 保存并试听，确认音色和语速。试听仅产生可清理缓存，不填充课程音频清单。
4. 点击“生成 / 继续整课音频”。明确生成后才向供应商发送课程原文。
5. 整课完成后播放长期保存在课程目录的资源，后续学习不重复转换；调整语速不重新生成。

设备模式仍可使用已安装的离线英语 TTS，作为尚未生成音频时的朗读方式。AI 模式下未就绪的片段提示家长生成，不在学习流程自动请求转换。

## 2. 保存、续作和重测

应用私有 filesDir/course-audio 的资源不受试听缓存淘汰、Key 删除或档案切换影响。不同音色的整课生成支持暂停、进入后台暂停及重启后继续缺失项；已有整课在新音色完成前继续使用，全部完成才切换。

“删除本课音频”需要明确确认，删除本课所有音色版本，包括未完成版本；保留 API 配置、试听缓存、孩子档案和学习记录。删除后恢复 0 / 44，可以使用同一配置重新测试生成。不存在删除后自动导入默认音频的分支。

升级不自动删除已有资源。若之前安装并运行过带音频的 0.1.3，本机可能仍有它已导入的课程文件；在家长空间确认删除本课音频即可回到空资源状态，无需卸载或清除整个应用数据。

当前长期保存仍不包含卸载后的自生成资源恢复、跨设备导出或云备份。删除课程音频是显式操作，不会因为新 APK 不含音频而自动清除用户已生成的内容。

## 3. 包体约束

[构建门禁](../scripts/assert-no-bundled-audio.mjs)检查 public、Vite dist 以及 Capacitor 同步后的 Android assets：拒绝音频扩展名文件及 course-audio 路径下的预制文件。最终 APK 再解包扫描确认零音频、零预制课程文件、无实际 Key 和 .env。

之前生成的样本移动到忽略的 artifacts/course-audio-samples-0.1.3，仅保留本机历史验证材料；不参与 Vite 或 Android 构建。开发机 [采样工具](../scripts/generate-course-audio.mjs)也改为只写 artifacts，没有把音频写回 public 的路径。本轮不使用用户 .env 执行合成或向手机导入 Key，首次转换留给用户配置和测试。
