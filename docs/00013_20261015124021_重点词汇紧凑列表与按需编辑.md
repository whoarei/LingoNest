# 重点词汇紧凑列表与按需编辑

建立时间：2026-10-15 12:40:21（Asia/Shanghai）。对应版本：0.1.12 / versionCode 13。

## 展示与操作

词汇整理步骤统一使用紧凑列表，适用于教材图片识别、应用建议和手动补充。顶部显示已选数量与总数；每项默认展示勾选框、英文词条、中文释义和编辑入口。来源、例句和编辑输入框仅在展开时显示，不再每项重复展示整张表单。

每次只展开一个词条；可修改词条、释义和例句，或删除该项。“完成”、再次点击当前词条或打开另一词条会收起编辑。勾选框独立操作，不需要展开。取消选择的项仍留在列表，可重新选择。

“补充词汇”创建选中的空词条并展开，焦点进入词条输入框。确认词汇时仍校验所有选中项；发现词条或释义缺失会展开并定位到首个不完整项。没有选中项时禁止继续，数量上限仍为 80。收起和展开只影响显示，不取消编辑；内容沿用原有延时自动保存和显式保存。

短释义完整展示，长释义在收起时最多显示两行，展开后可查看和修改全文。编辑状态不保存，重新进入课程默认收起所有项。课程生成、审核和已确认的词汇结构保持原有行为，不迁移数据。
