# 英语小窝 0.1.16

建立时间：2026-10-24 21:50:10（Asia/Shanghai）。包名 `cn.lingonest.app`，Android 构建号 `17`，最低 Android 7.0（API 24），目标 API 36。

## 本版变化

- 首次通过 [GitHub Releases](https://github.com/whoarei/LingoNest/releases/tag/v0.1.16)分发正式签名 APK，按用户要求沿用 PeerLink 的 Android 发布证书。
- 接入 GitHub CI：单元测试、浏览器回归、类型检查、生产构建、原生单元测试和 Android 构建全部通过后，才构建并发布安装包。
- 发布前核对应用版本、标签、包名、签名和包内资源，附带 SHA-256 校验文件及签名证书指纹。
- 学习功能沿用 0.1.15：每关三次短课、情境迁移、听说闭环与结算，继续支持七步学习和课文闯关两种模式。

## 安装须知

**此前本地测试包使用 Debug 证书，本版改为发布证书，无法直接覆盖安装。** 请先自行保留需要的内容，再卸载旧 Debug 版本并安装本版；卸载会删除应用数据。从本版开始保持同一发布签名，后续版本可覆盖升级。

应用不预装课程音频和开发者凭据。家长需配置模型与语音服务，再准备教材、生成并审核课程和音频。仍使用旧合并快照的安装需重新建立孩子档案与教材；已有旧闯关发布课程需重新生成、完整审核并发布，才能启用三次短课。

下载本 Release 的 `lingonest-0.1.16-release.apk`；使用 `SHA256SUMS.txt` 核对文件完整性，`signing-certificate-sha256.txt` 用于核对发布证书。

真实设备录音、真实生成题库质量与儿童学习效果需另行验收。
