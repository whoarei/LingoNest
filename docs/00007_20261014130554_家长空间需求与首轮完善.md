# 家长空间需求与首轮完善

状态：2026-10-14 当前工作区已实现的首轮增补；已重新构建调试 APK 并覆盖安装到连接手机，安装结果见下方验证记录。

## 定位与边界

家长空间提供查看学习情况、处理人工确认、核对课程和管理孩子档案的工作台。左上角图标单击切换学习与家长空间；首次没有孩子档案时也可进入。离开练习前确认退出，保留既有恢复点。返回学习空间恢复原页面及滚动位置。

家长导航为概况、确认、报告、课程。档案从当前孩子按钮进入。进入设置继续保持家长空间身份，返回时恢复原栏目。学习档案按孩子隔离，模型配置与课程音频按设备共用。

模型、API Key、协议、音色、语速、试听和课程音频生成/清理继续放在设置里。家长课程页显示资源就绪情况，并链接到设置。设置中的档案入口链接到家长档案管理。

后续 0.1.5 已调整：课程音频生成、暂停续作和清理移入课程管理，模型配置仍保留设置；新增拍照/文字原文、词汇整理、生成审核及多课程学习流程。当前行为以[课程新建与多课程管理](00008_20261014152914_课程新建词汇确认与多课程管理.md)为准，本文保留首轮实施记录。

## 本轮功能

| 模块 | 已实现内容 |
|---|---|
| 概况 | 今日作答次数、阶段完成、已测与已掌握目标、待复习数量；待核对课文、待确认口语、薄弱目标、音频准备和最近练习 |
| 口语确认 | 待确认/已确认筛选；孩子、课程、任务及提交时间；参考原文；完整回听后确认；更正已确认结果；查看持久化确认记录 |
| 报告 | 七项能力的已测与已掌握目标；能力筛选；默认有作答记录，可切换全部目标；目标状态、复习时间、作答、参考答案、反馈、提示/重试/时间异常标记 |
| 课程 | 当前内置课程、原图放大、双语转录、按档案核对确认、音频就绪数量和设置入口 |
| 档案 | 首个及后续档案创建、选择孩子、修改昵称、删除档案；保留现有最多 8 个档案限制 |

## 成人确认与交互规则

- 浏览概况、报告、课程和口语记录无需算术题。
- 创建/修改档案、提交/更正口语评价、确认课文、进入删除操作前做成人防误触确认。当前仍使用 7 + 5，不宣称身份认证。
- 成人确认只在本次家长空间会话中使用；退出家长空间、重启或切换孩子后清除。
- 录音完整播放成功后才允许确认。停止回听、切换栏目或进入设置时停止播放；中断和错误不能形成已回听状态。
- 更正评价后需重新回听才可再次更正。切换孩子清除回听与待执行操作，防止把确认状态用于另一个孩子。
- 删除档案还需输入当前昵称，明确只删除该档案的学习记录和录音，保留其他档案、模型配置与课程音频。

## 报告与数据约束

报告使用既有学习事件投影，不改变学习引擎的评分或掌握阈值。阶段完成、单次通过和达到掌握门槛分别展示。提示作答、同轮重试、待确认录音不直接增加独立掌握证据；异常时钟记录单独标注。

家长浏览参考原文和报告不写入学生的答案暴露事件。口语更正追加 review 事件，以当前 reviewRevision 做并发检查；同一作答的有效评价被替换，原确认记录保留，不重复累加证据。

## 后续范围

教材图片/文字导入与校对编辑、学习计划、提醒、数据导出恢复，以及更强的家长验证方式保留为后续工作。本轮仅管理现有内置课程，未实现自动发音评分，不展示尚未采集的学习时长。
