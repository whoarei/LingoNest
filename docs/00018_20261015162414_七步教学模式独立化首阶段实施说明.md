# 七步教学模式独立化首阶段实施说明

建立时间：2026-10-15 16:24:14（Asia/Shanghai）。应用版本仍为 `0.1.14`，本次为代码结构重构，未发布新安装包。

对应[模式独立化方案](00017_20261015140801_课程设计模式独立化方案.md)的首阶段：现有七步模式的内容生成、课程结构、学习运行、评价、页面、报告和样式已经收拢到独立模块；应用入口通过注册表加载模式。其他教学方法可接入自己的核心与界面，不需要继承七阶段数据模型。

## 1. 本轮模块边界

| 位置 | 职责 |
|---|---|
| [contracts.ts](../packages/learning-modes/contracts.ts) | 模式身份、懒加载注册、任意类型的模式核心、快照 codec；通用图片、档案和音频清单 DTO |
| [seven-step/index.ts](../packages/learning-modes/seven-step/index.ts) | 七步核心入口，导出 `authoring/runtime/reporting/state` |
| [seven-step/authoring.ts](../packages/learning-modes/seven-step/authoring.ts) | 原文解析、词汇与教学草稿校验、七阶段题库编译 |
| [seven-step/prompts.ts](../packages/learning-modes/seven-step/prompts.ts) | 原文识别、词汇建议和教学草稿提示词 |
| [seven-step/engine.ts](../packages/learning-modes/seven-step/engine.ts) | 既有评分、证据投影与复习算法 |
| [seven-step/state.ts](../packages/learning-modes/seven-step/state.ts) | 既有快照结构、校验及 formatVersion 1 → 2 迁移 |
| [seven-step/reporting.ts](../packages/learning-modes/seven-step/reporting.ts) | 七步模式能力标签、学习报告与家长工作台数据整理 |
| [src/modes/seven-step](../src/modes/seven-step/Experience.vue) | 完整现有学习体验、运行服务、课程准备/审核和家长页面，以及模式样式 |
| [src/platform](../src/platform/snapshot-repository.ts) | 快照读写机制、语音控制、内容模型传输；不包含七步教学规则 |
| [registry.ts](../src/modes/registry.ts)、[ModeHost.vue](../src/modes/ModeHost.vue) | 已安装模式注册与界面挂载；公共宿主不识别阶段、题型或掌握百分比 |

七步核心只依赖模式契约及自身模块，不导入 Vue、Android 桥接或应用页面。模式界面与运行适配可以使用 Vue 和公共能力端口；其 `LearningUI`、阶段状态及报告类型均在模式内部。

现有家长工作台与档案操作界面随当前体验保留在七步适配层，公共档案 DTO、原生存储和模型配置仍复用。后续增加另一真实模式时，再建立跨模式共享课程/档案的持久化封套和全局选择入口，避免本轮同时改动历史事实的归属。

## 2. 首轮兼容约束

这一轮直接使用原有的存储数据：

- 浏览器 key 仍为 `lingonest.local.v1`，仍读取 `{ revision, payload }`。
- Android 仍调用原有 SQLite 快照接口和 `expectedRevision`，没有修改数据库或原生 Java。
- 快照仍为 `LocalState.formatVersion = 2`，真正的 v1 快照仍通过原迁移加载。
- 内置课程 ID/版本、自建课程 ID/版本、题目 ID、题族、知识点及学习事件均保留。
- 阶段推进、评分 `policyVersion = "2"`、人工口语复核和复习规则保持原解释。
- 音频清单、课程资源键及既有图片/录音路径保留，不重新请求模型生成。
- 旧课程的草稿、已发布内容、已删除记录及资源清理待办仍由原规则校验。

模式身份 `seven-step@1` 是本次代码注册信息，不被伪装成旧课程新版本，也不自动写入旧作答。读取未知或损坏快照时拒绝写入，保留原内容。

重构前保存了[兼容样本](../tests/fixtures/seven-step-legacy.json)，包含旧自建课程、两份孩子档案、作答事实及未完成的提示练习恢复点，并记录原内置课程/题库、音频规格、自建编译包和学习投影的 SHA-256。重构后直接比对这些固定结果。

## 3. 共享能力与历史导入路径

快照仓储使用注入的 `SnapshotCodec<TState>`：公共层执行读取、revision 检查、容量检查和原子写入，具体数据解释由模式提供。七步模式的仓储适配使用原 key 和原 codec。

公共语音控制器必须显式传入课程音频清单，不再暗中加载七步内置课程；内容传输也不包含七步提示词。模式可复用音频与模型能力，使用自己的输入、资源清单和结果解析。

保留 `src/course.ts`、`src/course-library.ts`、`src/useLearning.ts`、`src/storage.ts`、`src/parent-report.ts`、`packages/learning-engine/src/*` 等历史入口作为薄兼容出口。`src/useSpeech.ts` 保留旧调用者的默认内置课程行为，新的公共能力入口为 [platform/speech.ts](../src/platform/speech.ts)。现有实现没有复制保留两份。

已移动的 Vue 组件引用更新为模式内路径，并同步修正文档链接。公共 `src/style.css` 只保留历史 CSS 导入出口；实际模式样式由 `Experience.vue` 懒加载，宿主不加载七步样式。

后续隔离修复将七步样式限定到 `seven-step-mode` 根节点，动画单独命名，公共层仅保留视口边距重置；语音控制器按资源所有权在作用域卸载时停止播放和生成。修复及完整回归见[模式卸载与样式隔离修复验证](../issues/00021_20261015173036_模式卸载与样式隔离修复验证.md)。

## 4. 其他模式如何接入

注册入口为 [seven-step/register.ts](../src/modes/seven-step/register.ts)。新的模式提供独立的体验组件和核心实现，再加入注册表。体验可以使用自己的首页、会话流程、审核、状态和报告，不要求包含 `StageId`、`Exercise` 或现有学习引擎类型。

```ts
const anotherRegistration = {
  identity: { id: "another-method", version: "1", title: "另一种教学方法" },
  loadExperience: async () => (await import("./another-method/Experience.vue")).default,
};
```

这是接口示例，不是已经安装的第二模式。注册表拒绝重复模式、不合法身份和未知默认值；查找未安装模式时明确报错，不自动退回七步模式。

当前只安装七步模式，因此宿主固定加载唯一的已注册默认模式。本轮没有提供假模式、切换按钮或无内容的多邻国入口。后续模式接入时应继续遵守已确认需求：家长空间一个全局选择，作用于所有课程；同一课程保留多模式内容；缺少当前模式时补生成并审核。

原生仓储目前仍是一个完整快照槽，不能把第二模式的独立快照直接写进去覆盖七步数据。真正接入第二模式前，需要先对共享课程/档案与各模式载荷实施显式的多模式封套迁移，并保存当前全局模式。该步骤没有被本轮泛型仓储接口自动完成。

## 5. 验证与范围

验证记录见[七步模式独立化重构与兼容验证](../issues/00019_20261015162414_七步模式独立化重构与兼容验证.md)。重点包括固定结果比对、旧快照读取、练习恢复、多档案隔离、完整课程准备、审核、音频与返回导航。

本轮保持教学行为等价，尚未修正原方案中的题族覆盖缺口，也没有实现多邻国式算法、全局模式切换或新多模式存储结构。源码和模拟服务回归不能代替真实模型与手机安装验证；本次未修改手机现有安装或数据。
